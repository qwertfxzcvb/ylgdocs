# 皮肤站

YLG 皮肤站用于绑定游戏角色、上传皮肤与披风，并支持高清皮肤。

- **皮肤站地址**：[https://skin.ylg.net.cn/](https://skin.ylg.net.cn/)

标准皮肤无需安装任何 MOD，只需完成以下三步即可更换。

## 更换皮肤

### 1. 在游戏内获取验证码

进入服务器后，在聊天框输入：

```
/skin
```

服务器会发送一个 **6 位数字验证码**。

::: tip 验证码有效期
验证码有效期为 **10 分钟**。过期后重新输入 `/skin` 即可获取新的验证码。
:::

### 2. 在网站绑定角色

使用官网账号登录皮肤站，然后进入 [角色管理](https://skin.ylg.net.cn/index.php)，填写游戏内获取到的验证码完成绑定。

角色绑定费用：

| 角色数量 | 所需积分 |
|---------|---------|
| 第 1 个角色 | 免费 |
| 第 2 个角色 | 100 积分 |
| 第 3 个及以后 | 每个 200 积分 |

绑定角色所消耗的是 **官网积分**。

### 3. 上传并应用皮肤

进入 [上传页面](https://skin.ylg.net.cn/upload.php)，上传一张 PNG 图片并应用到对应角色。

应用完成后，需要 **退出服务器并重新进入** 才会更新皮肤。

::: warning 注意
皮肤不会在游戏过程中即时刷新，更换后必须重新进入服务器一次。
:::

## 高清皮肤与披风

Minecraft 原版客户端仅支持标准的 **64×64 皮肤**，同时也不支持自定义披风。

如果需要显示高清皮肤或披风，需要安装对应的客户端 MOD。

不安装 MOD 也不会影响正常游戏。

### 显示规则

高清皮肤与披风是否能够显示，取决于 **观看者本人** 是否安装了皮肤 MOD，而不是材质所有者。

安装 MOD 后，可以看到服务器内其他玩家的高清皮肤与披风；未安装时，只会显示标准皮肤，并且不会显示自定义披风。

| 材质类型 | 未安装 MOD | 已安装 MOD |
|---------|------------|------------|
| 标准皮肤 64×64 | 正常显示 | 正常显示 |
| 高清皮肤 128×128 及以上 | 不显示 | 显示原图 |
| 披风 | 不显示 | 正常显示 |

::: tip 建议
角色的不同材质槽相互独立。

如果使用高清皮肤，建议同时为标准皮肤槽准备一张 **64×64** 的皮肤，这样未安装 MOD 的玩家也可以正常看到你的皮肤。
:::

## 安装皮肤 MOD

以下两种方式任选其一，**不要同时安装**。

### YLGSkin

YLGSkin 是 YLG 皮肤站配套的客户端 MOD，已经内置皮肤站地址，安装后无需额外配置。

目前仅支持 **Minecraft 26.2**。

请根据客户端使用的 MOD 加载器下载对应版本，不同加载器的文件不能混用。

- [前往 YLGSkin 下载页](https://skin.ylg.net.cn/download.php)

如果使用其他 Minecraft 版本，请使用下方的 CustomSkinLoader。

### CustomSkinLoader

CustomSkinLoader 支持较多 Minecraft 版本，适合旧版本客户端使用。

安装后需要手动添加 YLG 皮肤源。

打开游戏目录中的：

```
CustomSkinLoader/CustomSkinLoader.json
```

在 `loadlist` 的最前面加入：

```json
{
    "name": "YLG",
    "type": "CustomSkinAPI",
    "root": "https://skin.ylg.net.cn/csl/"
}
```

保存文件后重新启动游戏即可生效。

::: warning 注意
`root` 地址最后的 `/` 不可省略。
:::

## 常见问题

### 更换皮肤后，游戏内仍然显示旧皮肤

请先退出服务器，然后重新进入。

如果重新进入后仍未更新，可以等待一到两分钟后再次尝试，服务器侧可能存在缓存。

### 是否必须安装 MOD？

**标准皮肤不需要。**

服务器会将标准皮肤分发给所有玩家。

高清皮肤与披风则必须安装客户端 MOD 才能显示，因为 Minecraft 原版客户端仅支持 64×64 皮肤，并且不支持自定义披风。

### 上传了披风，为什么游戏内看不到？

披风需要安装客户端 MOD 后才能显示。

同时，披风是否可见取决于 **观看者本人** 是否安装 MOD。

安装后可以看到自己和其他玩家的披风；未安装的玩家则不会看到任何自定义披风。

### 图片有什么格式要求？

上传图片必须为 **PNG 格式**。

标准皮肤推荐使用：

- `64×64`
- `64×32`（旧版格式）

皮肤需要保持正确比例，因为角色身体各部分在图片中的位置是固定的。

如果尺寸不标准，系统会自动缩放到最接近的合法尺寸，但图片比例必须正确。

高清皮肤支持：

- `128×128`
- `256×256`
- `512×512`

高清皮肤需要安装客户端 MOD 后才能显示。

披风不限制图片尺寸，上传后会自动处理为游戏所需的格式。

### Steve 和 Alex 有什么区别？

主要区别是手臂宽度：

| 模型 | 手臂宽度 |
|------|----------|
| Steve | 4 像素 |
| Alex | 3 像素 |

如果选择错误，可能导致手臂显示异常。

上传后可以在材质详情页修改模型类型。

### 为什么不能自己填写角色名？

角色绑定必须通过服务器发送的验证码完成。

验证码可以证明对应游戏角色确实由本人使用，从而避免其他玩家填写别人的游戏 ID 并修改其材质。

### 解绑角色后积分会退还吗？

不会。

角色解绑后，已经消耗的积分不会退还。

如果之后重新绑定，需要按照当前角色数量重新支付积分，请在解绑前确认。

### 游戏内改名后应该怎么处理？

服务器运行在离线模式下。

修改游戏 ID 后，服务器会将新名称识别为另一个玩家，原有游戏数据也不会自动互通。

皮肤站需要重新绑定新的游戏 ID，并按照角色数量重新计算绑定费用。

### 发布到皮肤广场需要多久审核？

提交公开申请后会进入人工审核队列，通常会在 **1～2 天** 内处理。

如果皮肤仅供自己使用，则无需发布到皮肤广场，上传后即可直接应用。

### 忘记密码或需要修改邮箱

皮肤站与官网使用同一个账号。

如需修改账号信息，请前往：

- [官网账号设置](https://www.ylg.net.cn/settings.php)
