# 入服教程

进入 YLG 服务器前，需要先完成白名单申请。白名单通过后即可正常连接服务器。

## 服务器信息

| 项目 | 内容 |
|------|------|
| **服务器地址** | `ylg.net.cn` |
| **游戏版本** | 支持 `1.7` - `26.2`，推荐 **26.2** |
| **服务器核心** | Paper（基于 26.2） |
| **客户端类型** | 仅支持 **Java 版** |

::: warning 版本说明
- 服务器始终保持最新版本，Minecraft 发布新版后通常 **1-2 个月内** 完成更新
- 支持 `1.7` 及以上版本进入，但 **强烈推荐使用 1.21 及以上版本**
- 最佳体验版本为 **26.2**（与服务器端版本一致）
:::

## 申请白名单

为了优化服务器环境、提升整体游戏体验，并保障服务器稳定运行与玩家账号安全，进入服务器前需要先完成白名单申请。

### 推荐申请

推荐使用服务器的 **AI 自动审核系统**：

- [申请白名单](https://www.ylg.net.cn/whitelist.php)
- 全程自动完成审核
- 正常情况下 **1 分钟内** 即可完成
- 审核结果会自动发送至申请时填写的邮箱

::: tip 推荐
建议优先使用 AI 自动审核，通常可以很快完成白名单申请。
:::

### 备用申请

如果 AI 审核无法正常使用，可以通过人工审核通道申请：

- [人工审核申请](https://wj.qq.com/s2/27066207/2def/)
- 审核时间通常为 **7～30 天**
- 审核完成后，结果会发送至申请时填写的邮箱

### 申请须知

- 请认真填写申请信息，并确保内容真实、准确
- 请勿重复提交申请，以免影响审核效率
- 提交后请耐心等待，无需私信或 @ 管理员询问审核进度
- 白名单通过后再按照下方教程进入服务器


如果需要申请开设小号，请联系管理员，并提供：

- 小号游戏名称（ID）
- 申请开设小号的理由

## 如何进入服务器

### 1. 准备客户端

确保你拥有 Minecraft Java 版客户端。推荐使用以下启动器：

- [PCL2](https://afdian.com/a/LTCat) — 国内常用启动器
- [HMCL](https://hmcl.huangyuhui.net/) — 简洁易用

> 如需安装优化 MOD 提升帧率，请参考 [客户端推荐](/guide/client)

### 2. 添加服务器

1. 打开 Minecraft，点击 **多人游戏**
2. 点击 **添加服务器**
3. 服务器名称随意填写，如 `YLG`
4. 服务器地址填写：`ylg.net.cn`
5. 点击 **完成**，然后双击服务器即可加入

### 3. 首次进服

1. 确认白名单已经审核通过
2. 进入服务器后，你会出现在登录大厅
3. 输入 `/reg <密码> <重复密码>` 注册账号（详见 [注册账号](/account/register)）
4. 注册成功后输入 `/login <密码>` 登录
5. 建议立即完成 [绑定 QQ](/account/bindqq)

::: tip 新手建议
进服后记得阅读 [服务器规则](/guide/rules)，避免误触红线导致处罚。
:::
