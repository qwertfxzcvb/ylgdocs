# 入服教程

进入 YLG 服务器前，需要先完成白名单申请。白名单通过后即可正常连接服务器。

## 服务器信息

| 项目 | 内容 |
|------|------|
| **服务器地址** | `ylg.net.cn` |
| **游戏版本** | 支持 `1.7` - `26.3`，推荐 **26.3** |
| **服务器核心** | Leaf（基于 26.3） |
| **客户端类型** | 仅支持 **Java 版** |

::: warning 版本说明
- 服务器始终保持最新版本，Minecraft 发布新版后通常 **1-2 个月内** 完成更新
- 支持 `1.7` 及以上版本进入，但 **强烈推荐使用 1.21 及以上版本**
- 最佳体验版本为 **26.3**（与服务器端版本一致）
:::

## 申请白名单

为了优化服务器环境、提升整体游戏体验，并保障服务器稳定运行与玩家账号安全，进入服务器前需要先完成白名单申请。

### 在官网申请

1. 在 [官网](https://www.ylg.net.cn/register) 注册网站账号
2. 打开 [申请白名单](https://www.ylg.net.cn/whitelist)，如实填写问卷并提交
3. 提交后约 **1 分钟** 完成自动审核，结果会发送至注册邮箱

::: tip 无法申请？
如果官网无法访问，或因其他原因无法完成申请，请联系管理员 QQ `1444001949` 申请白名单。
:::

### 申请须知

- 请认真填写申请信息，并确保内容真实、准确
- 请勿重复提交申请
- 白名单通过后再按照下方教程进入服务器

### 附加账号（小号）

主账号通过审核后，可以在 [申请白名单](https://www.ylg.net.cn/whitelist) 页面的「添加附加账号」中，花费 **100 积分** 为同一网站账号再开通一个游戏名，无需重新审核。积分可通过官网每日签到和邀请好友获得，详见 [官网使用](/guide/website#签到、积分与等级)。

## 如何进入服务器

### 1. 准备客户端

确保你拥有 Minecraft Java 版客户端。推荐使用以下启动器：

- [PCL2](https://afdian.com/a/LTCat) — 国内常用启动器
- [HMCL](https://hmcl.huangyuhui.net/) — 简洁易用

> 如需安装优化 MOD 提升帧率，请参考 [客户端推荐](/guide/client)

### 2. 添加服务器

1. 打开 Minecraft，点击 **多人游戏**
2. 点击 **添加服务器**
3. 服务器名称随意填写，如 `YLG`
4. 服务器地址填写：`ylg.net.cn`
5. 点击 **完成**，然后双击服务器即可加入

### 3. 首次进服

1. 确认白名单已经审核通过
2. 进入服务器后，你会出现在登录大厅
3. 输入 `/reg <密码> <重复密码>` 注册账号（详见 [注册账号](/account/register)）；如果已经在官网为该账号 [设置过游戏密码](/account/resetpassword)，直接输入 `/login <密码>` 登录即可
4. 之后每次进服输入 `/login <密码>` 登录
5. 建议立即完成 [绑定 QQ](/account/bindqq)

::: tip 新手建议
进服后记得阅读 [服务器规则](/guide/rules)，避免误触红线导致处罚。
:::
