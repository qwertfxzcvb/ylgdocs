# 入服教程

## 服务器信息

| 项目 | 内容 |
|------|------|
| **服务器地址** | `ylg.net.cn` |
| **游戏版本** | 支持 `1.7` - `26.2`，推荐 **26.2** |
| **服务器核心** | Paper（基于 26.2） |
| **客户端类型** | 仅支持 **Java 版** |

::: warning 版本说明
- 服务器始终保持最新版本，Minecraft 发布新版后通常 **1-2 个月内** 完成更新
- 支持 `1.7` 及以上版本进入，但 **强烈推荐使用 1.21 及以上版本**
- 最佳体验版本为 **26.2**（与服务器端版本一致）
:::

## 如何进入服务器

### 1. 准备客户端

确保你拥有 Minecraft Java 版客户端。推荐使用以下启动器：

- [PCL2](https://afdian.com/a/LTCat) — 国内最流行的启动器
- [HMCL](https://hmcl.huangyuhui.net/) — 简洁易用

> 如需安装优化 MOD 提升帧率，请参考 [客户端推荐](/guide/client)

### 2. 添加服务器

1. 打开 Minecraft，点击 **多人游戏**
2. 点击 **添加服务器**
3. 服务器名称随意填写，如 `YLG`
4. 服务器地址填写：`ylg.net.cn`
5. 点击 **完成**，然后双击服务器即可加入

### 3. 首次进服

1. 进入服务器后，你会出现在登录大厅
2. 输入 `/reg <密码> <重复密码>` 注册账号（详见 [注册账号](/account/register)）
3. 注册成功后输入 `/login <密码>` 登录
4. 建议立即完成 [绑定 QQ](/account/bindqq)

::: tip 新手建议
进服后记得阅读 [服务器规则](/guide/rules)，避免误触红线导致处罚。
:::
