# 客户端推荐

## 推荐整合包

### Sodium Plus

**Sodium Plus** 是一个轻量级优化整合包，集成了多个性能优化 MOD，安装即用，无需手动配置

- 🔗 [Modrinth 下载](https://modrinth.com/modpack/sodiumplus)

::: tip 推荐理由
开箱即用，帧率通常可以提升 **3-5 倍**，适合不想折腾的玩家
:::

## 手动安装优化 MOD

如果你更喜欢自己搭配，以下是推荐的优化 MOD 列表：

| MOD | 作用 | 链接 |
|-----|------|------|
| **Sodium** | 渲染优化，大幅提升帧率 | [Modrinth](https://modrinth.com/mod/sodium) |
| **Lithium** | 服务端逻辑优化（单人同样有效） | [Modrinth](https://modrinth.com/mod/lithium) |
| **Starlight** | 光照引擎优化 | [Modrinth](https://modrinth.com/mod/starlight) |
| **LazyDFU** | 加速游戏启动 | [Modrinth](https://modrinth.com/mod/lazydfu) |
| **EntityCulling** | 不渲染看不到的实体 | [Modrinth](https://modrinth.com/mod/entityculling) |
| **FerriteCore** | 降低内存占用 | [Modrinth](https://modrinth.com/mod/ferrite-core) |
| **ModernFix** | 综合性能修复 | [Modrinth](https://modrinth.com/mod/modernfix) |

::: warning 注意事项
- 以上 MOD 均基于 **Fabric** 模组加载器，请先安装 [Fabric Loader](https://fabricmc.net/)
- 不要同时安装 **OptiFine** 和 **Sodium**，它们互相冲突
- 某些 MOD 可能触发服务器反作弊，如遇问题请参考 [常见问题](/guide/faq)
:::
