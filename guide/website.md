# 官网使用教程

烟翎阁官网 [www.ylg.net.cn](https://www.ylg.net.cn) 是申请白名单、管理游戏账号和参与社区的地方。

## 注册与登录

1. 打开 [注册页面](https://www.ylg.net.cn/register)，填写用户名、密码和邮箱
2. 点击「发送验证码」，填入发到邮箱的验证码
3. 阅读并同意《用户协议》和《隐私政策》，点击「立即注册」

也可以直接使用 **Microsoft、Google、GitHub** 账号登录，无需单独注册。

::: tip 忘记网站密码
在 [登录页](https://www.ylg.net.cn/login) 点击「忘记密码？」，填写注册邮箱，按邮件中的一次性链接重新设置密码。
:::

## 申请白名单

登录后打开 [申请白名单](https://www.ylg.net.cn/whitelist)，如实填写问卷并提交，约 **1 分钟** 完成自动审核，结果会发送至注册邮箱。

如果官网无法访问，或因其他原因无法完成申请，请联系管理员 QQ `1444001949` 申请白名单。

审核通过后，白名单页面的「我的游戏账号」中会列出你的游戏账号，可以在这里：

| 功能 | 说明 |
|------|------|
| **设置 / 重置游戏密码** | 修改进入服务器时 `/login` 使用的密码，详见 [重置密码](/account/resetpassword) |
| **添加附加账号** | 每个花费 **100 积分**，为同一网站账号再开通一个游戏名，无需重新审核，数量不限 |
| **查看处罚** | 账号受到处罚时会显示原因和期限，可以查看详情或提交申诉 |

::: warning 注意
游戏账号添加后不能删除或改名，如需调整请联系管理员。
:::

## 个人中心

点击右上角头像进入 [个人中心](https://www.ylg.net.cn/profile)。

### 签到、积分与等级

- **每日签到**：在个人中心或头像菜单中签到，每次获得 **20 积分** 和经验
- **积分**：可通过每日签到、邀请好友、附件被其他玩家购买等方式获得，用于发布主题（每个 **5 积分**）、兑换个性装扮、购买附件、添加附加账号
- **经验与等级**：每日登录、签到、发帖、回复、获得点赞等都会获得经验，经验只增不减，每种行为每天有获得上限

### 邀请好友

个人中心中有你的 **邀请码**。好友申请白名单时填写此邀请码，对方通过白名单后你可获得 **100 积分**。

### 个性装扮

用积分兑换头像框、昵称标识和徽章，装扮会展示在个人主页和社区里。

### 账号安全

- 可以绑定邮箱、设置登录密码、绑定 Microsoft / Google / GitHub 账号
- 「登录设备」中列出当前可以登录你账号的设备，不认识的请立即退出并修改密码
