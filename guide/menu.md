# 服务器菜单

在游戏内输入以下命令打开服务器主菜单：

```
/cd
```
或
```
/menu
```

也可以使用背包中的 **指南针** 右键打开菜单。

## 菜单功能一览

### 🗺️ 传送

| 功能 | 说明 | 命令 |
|------|------|------|
| **主城传送** | 传送至主城，服务器主要活动与交流中心 | `/res tp shengcun` |
| **随机传送** | 随机传送至未知区域，探索全新的资源点与生存环境 | `/rtp` |
| **家园管理** | 查看并传送至已设置的个人家园，支持创建与管理多个家园坐标点 | `/home` |
| **远程传送申请** | 向在线玩家发起远程传送请求，可通过在线玩家列表快速选择目标 | `/tpa` |
| **地标** | 浏览并传送至服务器各个地标，快捷前往活动点、商店与资源区域 | `/warp` |

### 💰 经济

| 功能 | 说明 | 命令 |
|------|------|------|
| **系统金融 / 支付中心** | 管理个人资产、转账与银行业务，快捷支付、查账与经济互动 | 点击图标打开菜单 |
| **全球贸易市场** | 进入玩家自由贸易市集，购买所需物资或寄售商品赚取金币 | `/market gui` |

[//]: # (> 详见 [系统金融]&#40;/economy/finance&#41; 和 [市场交易]&#40;/economy/market&#41;)

### 📦 实用工具

| 功能 | 说明 | 命令 |
|------|------|------|
| **个人仓库系统** | 左键直接打开个人仓库；右键打开扩容购买菜单 | `/inv` |
| **每日签到** | 每日登录即可领取签到奖励，连续签到福利更丰厚 | `/signin gui` |
| **礼包中心** | 领取或购买服务器专属礼包，新手礼包、进阶物资尽在其中 | `/kits` |
