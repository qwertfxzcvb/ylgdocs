# 常见问题

## 无法连接服务器

| 问题 | 解决方案 |
|------|----------|
| 提示"无法解析主机名" | 检查服务器地址是否输入正确：`ylg.net.cn` |
| 提示"连接超时" | 检查网络连接，尝试更换网络或使用代理 |
| 提示"版本不兼容" | 切换到 `1.7` - `26.3` 范围内的版本，推荐 `26.3` |

::: tip 如果还是无法解决
在确认服务器正常运行的情况下，尝试重启电脑或更换移动网络
:::

## 游戏卡顿 / 帧率低

- 安装优化 MOD 可以大幅提升帧率，详见 [客户端推荐](/guide/client)
- 降低渲染距离（建议 8-12 区块）
- 关闭不必要的光影和材质包

## 刷怪效率低

服务器使用 **Leaf** 核心，为保证服务器整体流畅运行，刷怪效率约为 **原版的 70%**

这是因为 Minecraft 原版的刷怪机制对服务器性能消耗极大，降低刷怪效率是目前所有大型服务器的通用做法，无法调整

::: tip 建议
设计刷怪塔/刷怪笼时，可以适当增大规模来弥补效率差异。
:::

## 投影 MOD（Litematica）

| 功能 | 是否可用 | 说明 |
|------|----------|------|
| **Litematica 投影** | ✅ 可用 | 正常使用投影功能没有问题 |
| **投影打印机（Printer）** | ⚠️ 需申请 | 默认会被反作弊拦截，可联系服主申请反作弊白名单 |

::: info 为什么打印机需要申请？
投影打印机会自动替你放置方块，这和外挂的「自动建造」在数据层面几乎一模一样，反作弊系统无法区分。如需使用打印机，请联系服主（QQ `1444001949`）申请反作弊白名单。

白名单仅限于使用投影打印机，**不得借此使用任何外挂功能**，一经发现将取消白名单并按规则处罚。
:::

## 正版 / 离线相关

| 问题 | 解答 |
|------|------|
| 服务器支持正版吗？ | 支持，正版和离线玩家均可进入 |
| 正版玩家名被占用 | 联系管理员 QQ `1444001949` 处理 |
| 皮肤不显示 | 请绑定皮肤站，具体参阅 [皮肤站](/guide/skin) |
