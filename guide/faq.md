# 常见问题

## 无法连接服务器

| 问题 | 解决方案 |
|------|----------|
| 提示"无法解析主机名" | 检查服务器地址是否输入正确：`ylg.net.cn` |
| 提示"连接超时" | 检查网络连接，尝试更换网络或使用代理 |
| 提示"版本不兼容" | 切换到 `1.7` - `26.2` 范围内的版本，推荐 `26.2` |

::: tip 如果还是无法解决
在确认服务器正常运行的情况下，尝试重启电脑或更换移动网络
:::

## 游戏卡顿 / 帧率低

- 安装优化 MOD 可以大幅提升帧率，详见 [客户端推荐](/guide/client)
- 降低渲染距离（建议 8-12 区块）
- 关闭不必要的光影和材质包

## 刷怪效率低

服务器使用 **Paper** 核心，为保证服务器整体流畅运行，刷怪效率约为 **原版的 70%**

这是因为 Minecraft 原版的刷怪机制对服务器性能消耗极大，降低刷怪效率是目前所有大型服务器的通用做法，无法调整

::: tip 建议
设计刷怪塔/刷怪笼时，可以适当增大规模来弥补效率差异。
:::

## 投影 MOD（Litematica）

| 功能 | 是否可用 | 说明 |
|------|----------|------|
| **Litematica 投影** | ✅ 可用 | 正常使用投影功能没有问题 |
| **投影打印机（Printer）** | ⚠️ 可能被踢 | 打印机的自动放置行为与外挂特征高度相似，反作弊系统无法区分 |

::: info 为什么不能放行打印机？
投影打印机的工作方式是自动替你放置方块，这和外挂的"自动建造"功能在数据层面几乎一模一样。如果放行打印机的检测，就等于同时放行了外挂的该功能，所以无法单独豁免。建议手动放置方块配合投影使用
:::

## 正版 / 离线相关

| 问题 | 解答 |
|------|------|
| 服务器支持正版吗？ | 支持，正版和离线玩家均可进入 |
| 正版玩家名被占用 | 联系管理员 QQ `1444001949` 处理 |
| 皮肤不显示 | 请绑定皮肤站，具体参阅 [皮肤站](/guide/skin) |
