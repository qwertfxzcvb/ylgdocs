# 重置密码

忘记了进入服务器时 `/login` 用的游戏密码，可以在官网自助重置，不需要联系管理员。

## 重置游戏密码

1. 登录 [官网](https://www.ylg.net.cn/login)（使用申请白名单时的网站账号）。
2. 打开 [申请白名单](https://www.ylg.net.cn/whitelist) 页面，在「我的游戏账号」中找到要重置的账号，点击右侧的 **重置游戏密码**。
3. 在弹出的窗口中确认身份：
   - 网站账号设置过登录密码的，输入 **网站登录密码**；
   - 使用 Microsoft、Google、GitHub 登录、没有设置网站密码的，点击「发送验证码」，输入发到注册邮箱的 **6 位验证码**。
4. 输入两次 **新的游戏密码**（8–30 位，可使用英文字母、数字和符号），点击 **确认修改**。

提交后账号旁会显示「密码修改中」，**约 1 分钟内生效**，完成后会发送邮件通知。之后进入服务器时使用新密码登录即可：

```
/login <新密码>
```

::: tip 提示
- 如果账号显示的是 **设置游戏密码**，说明该账号还没有在服务器里注册过。在这里设置后，第一次进入服务器时直接用这个密码 `/login` 登录。
- 每个账号每天最多修改 **3 次**，达到上限后请第二天再试。
- 游戏密码请不要与其他网站使用相同的密码。
:::

## 忘记网站登录密码

如果连网站的登录密码也忘了，在 [官网登录页](https://www.ylg.net.cn/login) 点击 **忘记密码？**，填写注册邮箱，按邮件中的一次性链接重新设置网站密码，再按上面的步骤重置游戏密码。

::: warning 没有收到邮件？
- 请检查 **垃圾邮件 / 广告邮件** 文件夹
- 确认邮箱地址输入正确
- 稍等几分钟后重试
:::

## 仍然无法找回

如果无法登录官网、注册邮箱也已无法使用，请联系管理员手动处理。
