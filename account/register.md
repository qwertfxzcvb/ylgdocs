# 注册与登录

## 1. 注册账号

首次进入服务器时，在聊天框输入以下命令完成注册：

```
/reg <密码> <重复密码>
```

**示例：**`/reg MyPass123 MyPass123`

::: tip 用户名被占用？
如果你第一次进入却提示需要登录，说明该玩家名已被其他人注册。

- **正版玩家**：请联系服主处理
- **非正版玩家**：请更换一个玩家名后重试
:::

## 2. 登录账号

进入服务器时，输入以下命令登录：

```
/login <密码>
```

**示例：**`/login MyPass123`

::: tip 提示
如果 IP 地址没有发生变化，之后进入服务器通常无需再次输入密码
:::

## 3. 修改密码

登录后即可更改密码：

```
/changepassword <旧密码> <新密码>
```

**示例：**`/changepassword MyPass123 NewPass456`

## 4. 忘记密码

| 情况 | 解决方式 |
|------|----------|
| 已绑定邮箱 | 参照 [重置密码](/account/resetpassword) 进行找回 |
| 未绑定邮箱 | 联系管理员手动重置 |
