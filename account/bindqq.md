# 绑定 QQ

> [!IMPORTANT]
> 完成 QQ 绑定后，您即可在群内使用各类指令功能，同时显著提升账号安全性

## 绑定流程

**1. 在服务器内发起绑定**

```
/easybot bind
```

系统会给你一个验证码，例如 `hccq`。
![示例](/bindqq/image1.png)


---

**2. 在 QQ 群内完成验证**

在服务器 QQ 群中发送：
```
绑定 <验证码>
```
**示例：**`绑定 hccq`
![示例](/bindqq/image2.png)
发送后机器人会自动确认，提示绑定成功。
![示例](/bindqq/image3.png)

[//]: # (:::)

## 解绑 QQ

如果需要解除绑定，在 QQ 群内发送：

```
解绑 <你的游戏名>
```

**示例：**`解绑 Steve`
![示例](/bindqq/image4.png)
::: info 自动解绑
退出 QQ 群后会自动解除绑定。
:::
