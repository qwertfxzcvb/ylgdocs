# 公益性领地

YLG服务器有着多个服务器/玩家设置的领地，供新老玩家使用。

## 传送指令

```
/res tp <领地名>
```
::: tip 小贴士
- 输入指令后，请保持**3秒内不移动**，否则传送将取消
:::
