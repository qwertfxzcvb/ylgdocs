# 创建领地

领地系统可以保护你的建筑不被其他玩家破坏或偷盗。

## 创建领地

1. 准备一把 **木锄**
2. **左键** 点击方块选择第一个角的位置（点 A）
3. **右键** 点击方块选择对角位置（点 B）
4. 输入命令创建领地：

```
/res create <领地名>
```

**示例：**`/res create home1234`

::: tip 领地范围
领地是一个长方体区域，从点 A 到点 B 的对角线构成
:::

## 网页领地地图

不想用木锄一点点选，也可以在网页上圈地和管理领地：

1. 在游戏里输入 `/lingdi`（也可以用 `/resauto`、`/ylgres`）
2. 点击聊天栏里的链接，在浏览器中打开
3. 网页上会显示你周围的 3D 地图，跟着你在游戏里的位置走

::: tip 链接说明
链接 **5 分钟内有效，只能打开一次**。过期了重新输入 `/lingdi` 获取即可
:::

在网页上可以：

- **圈地**：点「圈一块新领地」，在地图上点两个角，拖动边上的白色方块调整范围，填好名字后创建；也可以一键圈下自己所在的区块
- **查看领地**：自己的、别人的领地都会用边框标出来，点一下查看详情
- **管理领地**：修改权限、添加或移除成员、调整范围、新建子领地、改名、设置传送点、转让和删除

::: warning 注意
网页上的操作和游戏内命令效果一样，费用和领地数量上限也相同。需要在线时才能修改，离线时网页只能查看
:::

## 常用命令

| 命令 | 说明 |
|------|------|
| `/res set` | 设置领地权限 |
| `/res create <名称>` | 创建领地 |
| `/res remove <名称>` | 删除领地 |
| `/res tp <名称>` | 传送到领地 |
| `/res padd <领地名> <玩家名>` | 添加信任玩家 |
| `/res pdel <领地名> <玩家名>` | 移除信任玩家 |
| `/res info` | 查看当前所在领地的信息 |
| `/res list` | 查看自己拥有的所有领地 |

## 领地权限

你可以为信任的玩家设置不同的权限：

| 权限 | 说明 |
|------|------|
| `build` | 放置和破坏方块 |
| `use` | 使用门、按钮、箱子等 |
| `container` | 打开箱子、漏斗等容器 |
| `tp` | 传送到该领地 |

设置权限命令：
```
/res pset <领地名> <玩家名> <权限> true/false
```
