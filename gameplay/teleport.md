# 传送

服务器提供玩家互传、随机传送和返回上一位置等传送功能，也可以在 [服务器菜单](/guide/menu) 的「传送」分类中直接点击使用。

::: tip 传送等待
`/home`、`/warp`、`/back`、`/rtp`、`/tpa` 等传送在执行后需要原地等待 **3 秒**，期间移动会取消传送。
:::

## 玩家互传

| 命令 | 说明 |
|------|------|
| `/tpa <玩家名>` | 请求传送到对方身边；不填玩家名时打开在线玩家列表 |
| `/tpahere <玩家名>` | 请求对方传送到你身边 |
| `/tpaccept` | 接受传送请求 |
| `/tpdeny` | 拒绝传送请求 |
| `/tpacancel` | 取消自己发出的传送请求 |
| `/tptoggle` | 开启或关闭接收传送请求 |

传送请求 **60 秒** 内有效，超时后需要重新发送。

## 随机传送

```
/rtp
```

也可以使用 `/tpr`、`/wild`。

- 在主世界使用时，会传送到距离世界中心 **5000～20000 格** 范围内的随机安全位置
- 在下界、末地等部分世界使用时，会在当前世界内随机传送；在其他世界使用时，会传送回主世界的随机位置
- 两次随机传送之间需要间隔 **10 秒**

## 返回上一位置

```
/back
```

返回上一次传送前的位置；死亡后使用可以返回 **死亡地点**。

## 其他传送方式

| 功能 | 说明 |
|------|------|
| [设置家](/gameplay/home) | 保存常用位置，随时传送回去 |
| [地标传送](/gameplay/landmark) | 传送到其他玩家创建的公共地标 |
| [领地传送](/gameplay/residence) | `/res tp <领地名>` 传送到领地 |
