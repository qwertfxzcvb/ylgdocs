# 技能系统

YLG 服务器使用自研 **YLGMMO** 插件，为 Minecraft 添加了 RPG 技能系统。通过日常游戏行为获得技能经验、提升技能等级，解锁被动效果和主动技能。

技能系统定位为养成数值：被动效果的触发概率都在个位数到十几个百分点之间，主动技能只提供 I 级药水效果，不会改变原版战斗与采集的平衡。

## 查看技能

| 命令 | 说明 |
|------|------|
| `/mcstats` | 查看自己的所有技能等级 |
| `/inspect <玩家名>` | 查看其他玩家的技能等级 |
| `/mctop` | 查看技能等级排行榜 |
| `/mctop <技能名>` | 查看指定技能的排行榜 |

## 被动效果

被动效果达到解锁等级后自动生效。触发概率从解锁等级开始随等级逐步提高，到 **200 级** 时达到表中的最高概率。

## 主动技能

1. 手持对应工具（见下表）
2. **潜行 + 对空气右键**，或输入 `/mcability` 激活
3. 在持续时间内获得对应的药水效果

所有主动技能的冷却时间均为 **10 分钟**（从激活时开始计算），效果结束时会有提示。

| 工具 | 对应技能 |
|------|----------|
| 镐 | 采矿 |
| 锹 | 挖掘 |
| 剑 | 剑术 |
| 斧 | 斧术 |
| 弓、弩 | 箭术 |
| 钓鱼竿 | 钓鱼 |
| 骨头 | 驯兽 |
| 空手 | 格斗 |
