# 技能系统

YLG 服务器使用自研 **YLGMMO** 插件，为 Minecraft 添加了 RPG 技能系统。通过日常游戏行为提升技能等级，解锁特殊能力

## 查看技能

| 命令 | 说明 |
|------|------|
| `/mcstats` | 查看自己的所有技能等级 |
| `/mctop` | 查看技能等级排行榜 |
| `/mctop <技能名>` | 查看指定技能的排行榜 |


## 技能列表

### ⛏️ 采集类

| 技能 | 提升方式 | 特殊能力 |
|------|----------|----------|
| **Mining（挖矿）** | 挖掘矿石和石头 | 超级破坏器、双倍掉落 |
| **Woodcutting（伐木）** | 砍伐树木 | 一键伐木 |
| **Excavation（挖掘）** | 挖掘泥土、沙子等 | 挖出宝藏 |
| **Fishing（钓鱼）** | 钓鱼 | 稀有战利品、冰冻钓鱼 |
| **Herbalism（草药学）** | 采集农作物 | 双倍收获、自动补种 |

### ⚔️ 战斗类

| 技能 | 提升方式 | 特殊能力 |
|------|----------|----------|
| **Swords（剑术）** | 使用剑攻击 | 锯齿突刺、反击 |
| **Axes（斧技）** | 使用斧头攻击 | 暴击、破甲 |
| **Archery（箭术）** | 使用弓箭攻击 | 眩晕、追踪箭 |
| **Unarmed（格斗）** | 空手攻击 | 缴械、铁臂 |
| **Taming（驯兽）** | 驯服和使用动物 | 宠物增强 |

### 🔧 制作类

| 技能 | 提升方式 | 特殊能力 |
|------|----------|----------|
| **Repair（修理）** | 使用铁砧修理 | 超级修理、节省材料 |
| **Alchemy（炼金）** | 酿造药水 | 自定义药水配方 |
| **Smelting（冶炼）** | 使用熔炉 | 双倍产出、节省燃料 |

## 技能激活

部分技能拥有主动能力，使用方式：

1. 手持对应工具
2. **右键**准备技能
3. 立即开始使用工具（挖/砍/攻击）

技能会在短时间内生效，冷却后可再次使用。
