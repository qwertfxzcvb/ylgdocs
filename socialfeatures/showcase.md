
# 展示物品

在聊天栏中向其他玩家展示你手中的物品或背包内容。

## 展示手持物品

手持想要展示的物品，在聊天框中输入 `[i]`，发送后其他玩家可以点击查看物品详情。

**操作步骤：**
1. 手持要展示的物品
2. 在聊天框输入任意文字 + `[i]`
3. 发送消息

**示例：**
```
看看我的武器 [i]
```

其他玩家点击聊天中的物品标签即可查看附魔、名称等详细信息。

## 展示背包

在聊天框中输入 `[inv]`，发送后其他玩家可以点击查看你的背包内容。

**示例：**
```
我的背包 [inv]
```

## 展示末影箱

在聊天框中输入 `[ender]`，发送后其他玩家可以点击查看你的末影箱内容。

**示例：**
```
我的末影箱 [ender]
```
