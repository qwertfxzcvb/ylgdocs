# 音乐播放器

服务器内置网易云音乐播放器，可以在游戏里搜歌、听歌、建歌单，也可以邀请好友一起听，或者外放给周围的玩家。

::: warning 需要安装语音模组
音乐通过 [Simple Voice Chat](/guide/suggestedmods/simplevoicechat) 模组播放。未安装模组或未连接语音时，菜单可以正常打开，但听不到声音。
:::

## 打开播放器

有两种方式：

- 输入命令 `/music`（也可以输入 `/yy`）。
- 在播放器主页底栏点击「购买音乐播放器」，花费 **10 金币** 获得一个音乐播放器物品，之后拿在手上 **右键** 即可打开，不用输入命令。该物品无法放置。

服务器已提供网易云会员账号，无需登录自己的账号，会员歌曲也能播放。

## 主页

| 按钮 | 说明 |
|------|------|
| 搜索 | 在聊天框输入歌名、歌手或歌单名，结果分为歌曲、歌单、歌手三栏 |
| 正在播放 | 打开播放控制：上一首、暂停、下一首、进度跳转、音量、播放方式 |
| 我喜欢 | 喜欢过的歌曲 |
| 我的歌单 | 自建歌单和收藏的网易云歌单 |
| 排行榜 | 飙升榜、新歌榜、热歌榜等官方榜单 |
| 推荐歌单 | 网易云精选歌单 |
| 最近播放 | 最近播放过的 50 首 |
| 播放队列 | 接下来要播放的歌曲 |
| 一起听 | 邀请好友同步收听 |
| 设置 | 菜单样式、歌词位置与样式、音量等 |

## 歌曲操作

在任意歌曲上：

| 操作 | 效果 |
|------|------|
| 左键 | 立即播放（在歌单里为从这首开始播放） |
| 右键 | 加入播放队列 |
| Shift + 左键 | 喜欢 / 取消喜欢 |
| Shift + 右键 | 加入歌单（在自建歌单里为移出歌单） |

在「正在播放」界面可以切换播放方式：**列表循环**、**单曲循环**、**随机播放**。进度条左键快退 10 秒、右键快进 10 秒。

## 歌单

- **新建歌单**：在「我的歌单」点击「新建歌单」，输入名字即可，每人最多 20 个歌单。
- **收藏网易云歌单**：在歌单列表上 Shift + 点击即可收藏。
- **导入歌单**：点击「导入歌单」，粘贴网易云歌单链接或歌单 ID。
- **删除歌单**：在「我的歌单」里对歌单 Shift + 右键两次。

## 一起听与外放

### 一起听

在「一起听」里点击「邀请」，选择在线玩家发送邀请。对方点击聊天栏中的 **[加入]** 即可，邀请 60 秒内有效。

加入后所有成员听同一首歌，**每个人都可以切歌、暂停**。点击「离开」退出一起听。

### 外放

开启外放后，声音从你身上发出，周围 **32 格** 内的玩家都能听到，类似唱片机。可以在主页底栏或「正在播放」界面开关，也可以输入 `/music mode`。

::: tip 提示
服务器同时播放的会话有上限（一个人自己听、一组一起听、一个外放各算一个），满了会提示稍后再试。
:::

## 歌词

在「设置」里可以调整：

| 设置 | 选项 |
|------|------|
| 歌词位置 | 不显示、动作栏、字幕（两行）、BOSS 血条（两行）、悬浮歌词 |
| 歌词样式 | 经典、霓虹、卡拉OK、清新、樱花、落日、深海 |
| 逐字歌词 | 随演唱逐字点亮（部分歌曲支持） |
| 翻译歌词 | 外文歌曲在第二行显示翻译 |
| 悬浮歌词高度 | 视线上方 / 视线下方（仅悬浮歌词时有效） |

也可以输入 `/music lyric` 快速切换歌词位置。

## 音量

播放器默认音量为 80%，可以在「设置」或「正在播放」里调整。语音模组设置（按 **V**）中还有独立的「音乐」音量条，两者共同决定最终音量。

## 菜单样式

- **箱子菜单**：传统的物品栏界面。
- **实体菜单**：在面前浮现的悬浮面板。准星对准按钮会显示说明，左键 / 右键点击操作，进度条可以点击跳转；走开或点击 ✕ 会自动关闭。

在设置里或输入 `/music ui` 切换。

## 命令

| 命令 | 说明 |
|------|------|
| `/music` | 打开播放器 |
| `/music search 歌名` | 搜索歌曲 |
| `/music now` | 正在播放 |
| `/music like` | 我喜欢 |
| `/music next` / `prev` | 下一首 / 上一首 |
| `/music pause` | 暂停 / 继续 |
| `/music stop` | 停止播放（一起听时为离开） |
| `/music mode` | 开关外放 |
| `/music lyric` | 切换歌词位置 |
| `/music ui` | 切换菜单样式 |
| `/music settings` | 打开设置 |
| `/music buy` | 购买音乐播放器物品 |
| `/music help` | 打开帮助书 |

## 常见问题

| 问题 | 解决方法 |
|------|----------|
| 打开了播放器但听不到声音 | 确认已安装 Simple Voice Chat 并连接语音；检查语音设置中的「音乐」音量 |
| 某首歌被跳过 | 该歌曲暂无版权或已下架，换一首或换一个版本 |
| 想让朋友一起听 | 使用「一起听」邀请；只想让周围的人听到可以开外放 |
