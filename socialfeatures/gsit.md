# 坐姿与动作

服务器支持坐下、躺下、爬行等动作，可以用于休息、拍照或与其他玩家互动。

## 坐下

使用以下命令可以原地坐下：

```
/sit
```

部分方块也可以直接坐下，例如楼梯、台阶或地毯，只需对准方块右键即可。

## 爬行

使用以下命令进入爬行状态：

```
/crawl
```

进入后角色会贴近地面移动。

## 躺下

可以使用以下命令切换不同的躺姿：

| 命令 | 说明 |
|------|------|
| `/lay` | 躺下 |
| `/layback` | 仰躺 |
| `/bellyflop` | 趴下 |

## 旋转

使用以下命令可以进入旋转动作：

```
/spin
```

## 坐在其他玩家身上

部分情况下可以右键其他玩家坐在其身上，实现叠罗汉效果。

::: tip 提示
部分动作可能会受到所在区域、方块类型或当前状态限制，如果无法使用，可以更换位置后再次尝试。
:::
