# 异界行商联络器
![示例](/linsmagic/merchant0.png)
> [!IMPORTANT]
> 异界行商联络器关联着服务器经济体系，可在其中向异界行商卖出/购买魔法物品。

## 获取

```
/merchant
```

- 输入该指令，服务器会给予你一个`异界行商联络器`。
![示例](/linsmagic/merchant1.png)
::: tip 小贴士
- [芸集知识之书](/linsmagic/book)中包含了该物品菜单，无需重复获取。
:::
