# 网页机器教程

「网页机器」是可与网站联动的机器：玩家在游戏内获取一次性密钥，前往网页端进行操作，操作结果将返回至游戏内。目前最常用的是 **绘制台-WE**，可将任意图片转换为挂在墙上的地图画。

## 绘制台-WE：图片转地图画 {#s-drawing}

### 合成

所需材料均为原版物品：纸、墨囊、工作台、制图台、铁块、铁砧。

<AtlasRecipe id="drawing_table_we" />

### 使用步骤

1. 放置 <LmItem id="绘制台-WE" /> 后**右键**打开界面。
2. 点击界面中间的「获取绘制台-WE密钥」，聊天栏将显示一串密钥（**点击即可复制**）与网页地址 [machine.ylg.net.cn/canvas](https://machine.ylg.net.cn/canvas)。
3. 打开网页，粘贴密钥后点击「进入」。
4. 在编辑器中绘制图片，或点击「导入图片」上传图片，也可使用 `Ctrl+V` 粘贴剪贴板中的图片。
   - **抖动**：「弗洛伊德」「阿特金森」「有序」会通过点阵模拟更多颜色，照片类图片建议选择弗洛伊德；像素画、图标建议选择「无」。
   - 画笔、橡皮、填充、取色、直线、圆、矩形均可用于修图，`Ctrl+Z` 撤销。
5. 点击「发送地图」，待聊天栏提示完成后，**再次右键该绘制台**，从输出格取出地图画。若该绘制台已被拆除，地图将直接发放至背包，背包已满时掉落在脚下。
6. 将地图放入物品展示框，挂在墙上即可。

::: tip 密钥规则
- 每个密钥**仅可使用一次**，默认 24 小时后失效。如需再次绘制，请回到绘制台重新获取。
:::

### 常见问题

| 现象 | 原因 | 解决方法 |
| --- | --- | --- |
| 点击按钮后提示「密钥生成失败」 | 网页服务暂时无法连接 | 稍后重试；若持续失败请反馈给管理员 |
| 网页提示密钥无效 | 密钥已使用，或已超过 24 小时 | 回到绘制台重新获取 |
| 发送后游戏内未收到地图 | 网页与服务器之间存在数秒延迟 | 保持在线稍等片刻，再次右键绘制台查看输出格 |
| 颜色与原图差异较大 | 地图仅支持有限的几十种颜色 | 更换抖动方式，或先将图片调亮、提高对比度 |

## PyCo30 操作仪 {#s-pyco30}

<LmItem id="PyCo30操作仪" /> 是 PyCo30 系列网页操作台的初代机，用法与绘制台相同：放置后右键获取一次性密钥，按提示进入网页端。其网页功能**仍在开发中**，目前仅可进行连通测试，暂无需专门制作。合成需要 Py、Co 回路钢块等高级材料，完整合成树可在资料页查看。
