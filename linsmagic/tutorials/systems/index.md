# 系统教程

每篇讲透一个系统，不用按顺序读，想搭什么就看什么。每篇都是同一个结构：

1. **最小可用例子**：先让它跑起来，配 3D 示意图，可以拖动旋转，悬停方块看说明。
2. **进阶玩法**：一样样加功能。
3. **常见问题**：按「现象 → 原因 → 怎么办」排好，出问题直接查。
