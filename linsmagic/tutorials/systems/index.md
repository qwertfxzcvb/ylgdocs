# 系统教程

每篇教程介绍一个系统，无需按顺序阅读，可根据需要查看对应篇目。每篇均采用相同结构：

1. **最小可用示例**：先让系统运转起来，配有 3D 示意图，可拖动旋转，鼠标悬停方块可查看说明。
2. **进阶玩法**：逐步添加更多功能。
3. **常见问题**：按「现象 → 原因 → 解决方法」整理，便于排查问题。
