# 管道系统教程

管道能把一个容器里的东西自动抽出来，沿着玻璃管道送到另一个容器，路上还能分流、按物品分拣、计数、隔空传送。刷石机、农场、矿机的产物都可以用它自动收进仓库。

这篇从最简单的「两只箱子」讲起，先跑通一条线，再一样样加功能。每一节都有能拖动旋转的 3D 示意图，悬停方块看说明，点击方块打开资料页。

::: tip 读这篇需要多久
第 1～3 节大约 10 分钟，看完就能搭出第一条能用的管道。后面几节用到时再回来查。
:::

## 认识零件 {#s-parts}

先有个印象就行，不用背。搭最小链路只需要前三样。

| 零件 | 作用 | 什么时候用 |
| --- | --- | --- |
| <LmItem id="管道玻璃-A型" /> | 物品在里面跑的管子。A/B/C/D 四种颜色互不相通 | 任何线路 |
| <LmItem id="传出阀" /> | 从贴着的容器里**抽出**物品送进管道，每 0.5 秒 1 个 | 线路起点 |
| <LmItem id="传入阀" /> | 把管道里的物品**塞进**贴着的容器 | 线路终点 |
| <LmItem id="行通阀" /> | 贴着容器时既会从容器里抽，也会把路过的物品塞进容器；不贴容器时原木两端当管道用 | 一条线串多个箱子 |
| <LmItem id="下界合金管道-A型" /> | 速度 6 倍、单程 256 格的管道，和同型号普通管道相通 | 长距离主干 |
| <LmItem id="下界合金传出阀" /> | 一次抽一整组（最多 64 个） | 大批量出货 |
| <LmItem id="6向分流器" /> | 轮流发往每个接了管道的方向 | 一分多 |
| <LmItem id="均分分流器" /> | 把一组物品按数量平分给各出口 | 多台机器平均喂料 |
| <LmItem id="平衡分流器" /> | 优先送往剩余空间最多的终点箱 | 多个仓库箱均匀装 |
| <LmItem id="过滤-放行器" /> | 和样品一样的直走，其余拐弯 | 按物品分拣 |
| <LmItem id="过滤-调转器" /> | 和样品一样的拐弯，其余直走 | 把某几种挑出来 |
| <LmItem id="单向运输器" /> | 不用阀门，贴着容器直接抽，朝尖端方向送，只走水平 | 短距离、省阀门 |
| <LmItem id="管道侦测器" /> | 直通，有物品经过时让背后的比较器闪一下 | 做红石联动 |
| <LmItem id="末影发送口" /> + <LmItem id="末影接收口" /> | 不用管道，同一世界 50 格内隔空传送 | 跨过河流、山体 |
| <LmItem id="填充机核心" /> + <LmItem id="填充机输出口" /> | 一根管道把整排箱子从低到高装满 | 大仓库 |
| <LmItem id="跨维传送器" /> | 同名的两台放在不同维度，管道物品跨维度传送 | 下界 / 末地物流 |

还有几样用得少的：<LmItem id="吸纳整合桶" />（瞬间吸走正上方漏斗里的东西）、<LmItem id="排列器" />（凑够设定的组合才放行）、<LmItem id="潜影盒接收器" />（红石触发时把上方潜影盒整个收进管道）。点开资料页可以看详细说明。

管道玻璃很便宜：4 个铁锭 + 4 块黑色染色玻璃 + 1 个红石，**一次出 16 格**。贵的是阀门。搭下面那条最小链路（2 个阀门 + 3 格管道）大约要准备：

- **28 个铁锭**：一次管道合成用 4 个；每个阀门 12 个，含铁皮和漏斗。
- 4 块黑色染色玻璃、1 个红石、2 个红石块。
- 2 个侦测器：要下界石英，先去一趟下界。
- 2 个漏斗。
- 2 块遮光玻璃：要紫水晶碎片，地下的紫水晶洞里挖。

::: warning 必须是合成出来的管道玻璃
原版的黑色染色玻璃摆在那里不会变成管道。管道零件都是带魔法标记的物品，放下时才会登记进管道网络。
:::

## 第 1 节：搭第一条线 {#s-first}

<LmScene id="pipe-basic" />

按编号顺序放：

1. 放两只箱子，中间隔几格。
2. 手持 <LmItem id="传出阀" />，**准星对准左边箱子的侧面**，右键放上去。
3. 从阀门另一侧开始铺 <LmItem id="管道玻璃-A型" />，一直铺到右边箱子前一格。
4. 手持 <LmItem id="传入阀" />，**准星对准右边箱子的侧面**，右键放上去。它会自动和旁边的管道连上。
5. 往左边箱子里放几个圆石。每 0.5 秒会有 1 个从阀门钻出来，在管道里移动，最后进入右边箱子。

<figure class="lm-shot"><img src="/linsmagic/tutorials/pipe-running.webp" alt="游戏里的样子：物品在管道里移动，上方的数字是这一堆有几个。左边白色的是传出阀，右边深色的是传入阀。" loading="lazy" /><figcaption>游戏里的样子：物品在管道里移动，上方的数字是这一堆有几个。左边白色的是传出阀，右边深色的是传入阀。</figcaption></figure>

跑通了就说明你已经会了最核心的部分，后面所有玩法都是在这条线上加零件。

::: details 为什么每次只抽 1 个？
普通 <LmItem id="传出阀" /> 每 0.5 秒抽 1 个，也就是每秒 2 个，足够日常使用。要搬大量东西时换成 <LmItem id="下界合金传出阀" />，每 0.5 秒抽一整组。同一格管道里的同种物品会自动合成一堆，管道上方显示的数字就是这一堆有多少个。
:::

## 第 2 节：阀门方向（最容易出错的地方） {#s-valve}

**阀门认准的方向，由你放它时右键点的那个方块决定。**对着箱子放，它就认准箱子；对着管道放，它就认准管道。

<div class="lm-shot-row">
<figure class="lm-shot"><img src="/linsmagic/tutorials/valve-place.webp" alt="正确的放法：手持阀门，准星对准箱子的侧面，然后右键。" loading="lazy" /><figcaption>正确的放法：手持阀门，准星对准箱子的侧面，然后右键。</figcaption></figure>
<figure class="lm-shot"><img src="/linsmagic/tutorials/valve-placed.webp" alt="放好后阀门贴在箱子上，年轮朝向你。之后再从阀门的另一侧铺管道。" loading="lazy" /><figcaption>放好后阀门贴在箱子上，年轮朝向你。之后再从阀门的另一侧铺管道。</figcaption></figure>
</div>

阀门的外形是一根原木，两头都有年轮。对着箱子放和对着管道放，外观完全一样，可前者能用、后者永远不工作。所以：

- **先放箱子，再对着箱子放阀门，最后铺管道。**
- 如果线路不动，最快的办法是把阀门敲掉，重新对着箱子放一次。
- 行通阀、单向运输器同样按「点的是哪个方块」定方向。

::: tip 单向运输器的方向相反
<LmItem id="单向运输器" /> 放下后，**尖端背对你点的方块**。所以对着箱子放，它会从这个箱子抽东西，往尖端方向送出去。它只能水平摆放，放在地上或天花板上时会自动转成水平方向。
:::

## 第 3 节：管道怎么走 {#s-rules}

### 连接规则

- 管道零件在**上下左右前后 6 个方向**上，和相邻的管道零件自动相连，不需要额外操作。
- **A、B、C、D 四种管道玻璃之间不相通**。两条不同颜色的管道可以紧贴着并排走而互不干扰。阀门、分流器这类零件则和任何颜色都相连。
- 下界合金管道分 A～D 四个型号，和**同型号**的普通管道相通。
- **同颜色的两条管道贴在一起就会串线**，物品可能拐进隔壁那条。并排走线请用不同颜色。

### 遇到岔路

- 普通管道遇到分叉时，**随机**选一个方向，不会原路返回。
- 想要有规律地分配，就在分叉处放分流器（见第 4 节）。
- 走到死路（前面没有管道也没有阀门）时，物品会从那里**弹出掉在地上**。

### 速度与距离

| | 普通管道玻璃 | 下界合金管道 |
| --- | --- | --- |
| 移动速度 | 每秒 2 格 | 每秒约 12 格 |
| 单程最远 | 64 格 | 256 格 |

- 物品在哪种管道里就用哪种速度，可以混着铺。
- 单程距离在物品**刚离开阀门**时就定下来：阀门后面的第一格是下界合金管道，这批物品就能走 256 格，否则只能走 64 格。所以长线路的第一格一定要用下界合金管道。
- 超过距离的物品会掉在地上。

### 区块与拆除

- 物品走到未加载的区块时会暂停，区块重新加载后继续，不会丢。关服重启也会保留管道里正在跑的物品。
- 拆掉一格管道，里面正经过的物品会掉出来。

## 第 4 节：分流与分拣 {#s-split}

### 一分多

<LmScene id="pipe-split" />

三种分流器的区别：

| | 怎么分 | 适合 |
| --- | --- | --- |
| <LmItem id="6向分流器" /> | 每来一堆，轮到下一个出口 | 一般的分配 |
| <LmItem id="均分分流器" /> | 把一堆按数量平分（64 个、4 个出口 → 各 16 个），除不尽的余数轮流给 | 几台相同的机器平均喂料 |
| <LmItem id="平衡分流器" /> | 沿每个出口找到终点箱，送往剩余空间最多的那一路 | 几个仓库箱装得一样满 |

分流器的「出口」是除了来路以外、接着管道的面，上下也算。空着的面不会送东西。

### 按物品分拣

<LmScene id="pipe-filter" />

1. 在想分拣的位置放 <LmItem id="过滤-放行器" />，前后都接上管道。
2. **右键**它打开 5 格设置界面，放入样品，最多 5 种。样品只是模板，关掉界面后会记住，**不会被消耗**。
3. 和样品一样的物品**直走**；不一样的轮流拐向侧面（包括上下）接了管道的方向。
4. 侧面没接管道、或直走方向没接管道时，该走那边的物品会弹出来。

<figure class="lm-shot lm-shot-narrow"><img src="/linsmagic/tutorials/filter-gui.webp" alt="右键过滤器打开的设置界面：上面 5 格放样品，关掉界面自动保存。" loading="lazy" /><figcaption>右键过滤器打开的设置界面：上面 5 格放样品，关掉界面自动保存。</figcaption></figure>

魔法物品按「是哪种魔法物品」区分，不会和同材质的原版物品混淆。

<LmItem id="过滤-调转器" /> 的逻辑正好相反：一样的拐弯，其余直走。想从一大堆杂物里把某几样挑出来时用它。

::: tip 分拣整个仓库
把几个过滤器串在一条主线上，每个过滤器侧面接一个箱子，就是一台自动分类机：第一个挑圆石，第二个挑铁锭，第三个挑钻石……最后剩下的直走进「杂物箱」。
:::

## 第 5 节：给机器自动进出料 {#s-machine}

很多多方块机器用箱子进料、木桶出料。给它们接上管道，就能从仓库自动送料、把成品自动收走。下面以新手最早能做的 <LmItem id="原石粉碎机核心" /> 为例：

<LmScene id="crusher-auto" />

要点：

- **进料**：<LmItem id="传入阀" /> 对准机器的**输入箱**放。
- **出料**：<LmItem id="传出阀" /> 对准机器的**输出木桶**放。
- 机器自己的结构方块（四角的圆石）不要换成管道。阀门接在输入箱、输出桶的外侧就行。
- 管道能送进的是这些容器：箱子、陷阱箱、木桶、潜影盒、漏斗、发射器、投掷器。熔炉、高炉这类**不是**管道能直接送进的容器，要先送进漏斗，再让漏斗往下送。
- 少数机器有专门的管道入口。例如[原版矿机](/linsmagic/atlas/tutorials/systems/multiblock#s-ore-miner)的燃料，可以用传入阀直接对着矿机核心送煤炭或木炭。

## 第 6 节：远距离与大仓库 {#s-far}

### 末影发送口 / 接收口

<LmScene id="ender-link" />

- **不需要管道**：发送口贴着一个容器，接收口贴着另一个容器，频道名相同就会自动传输。
- 频道名的起法：右键接口 → 点「进行命名」→ 在聊天框输入名字（最多 32 个字，输入 `cancel` 取消）。起好后接口上方会浮着频道名。
- 两端必须在**同一个世界**，直线距离 **50 格以内**。同频道有多个接收口时，送往最近的那个。
- 速度只看**发送口**：普通发送口每 0.5 秒 1 个；<LmItem id="下界合金末影发送口" /> 每秒一整组（64 个）。
- 接收端的箱子满了，东西就留在原来的箱子里，不会丢。
- 想跨维度，请用 <LmItem id="跨维传送器" />：两台起相同的名字，分别放在**不同维度**，管道送进一台，另一台就会把物品吐进它旁边的管道。

### 填充机群：一根管道装满一整面墙的箱子

<LmScene id="filler-group" />

- 管道直接连到 <LmItem id="填充机核心" /> 上，不用传入阀。
- 核心和 <LmItem id="填充机输出口" /> 贴在一起就是一个「群」。群里每个方块旁边的箱子都会被装，**先装最低的**，满了再往上。
- 一个群最多 16 个方块（核心加输出口），超过就整个群失效，这时所有物品都走溢出。
- 填充机也分 A～D 四个型号，**只和同型号的连成群**。所以不同型号可以紧贴着放，互不干扰。
- 全部装满、或者核心被红石充能时，物品会改走核心上其它接着的管道（可以接到下一个填充群），没有就弹到地上。

## 红石控制 {#s-redstone}

<LmScene id="redstone-stop" />

| 通电的方块 | 效果 |
| --- | --- |
| 一格普通管道（或只连着两边的零件） | 物品停在它前面排队，断电后继续 |
| 传出阀 | 暂停从箱子抽取 |
| 传入阀 | 物品在门口等，断电后再送进箱子 |
| 岔路口（连着 3 个以上方向） | 可以强制物品只走某一侧（和周围哪一格带电有关，建议先搭测试线确认） |
| 填充机核心 | 当作箱子全满，全部走溢出 |

<LmItem id="管道侦测器" /> 是直通的。旁边放一个**背对它**的比较器，每经过一堆物品，比较器就输出一个短脉冲，可以用来在有货经过时触发别的红石机关。

## 常见问题 {#s-faq}

| 现象 | 最可能的原因 | 怎么办 |
| --- | --- | --- |
| 箱子里的东西一个都不出来 | 阀门是对着管道或地面放的 | 敲掉阀门，**对着箱子**重新放（[第 2 节](#s-valve)） |
| | 传出阀被红石充能了 | 检查旁边的拉杆、红石块、红石火把 |
| | 线路堵了（终点满了或被红石拦住），堵到阀门口 | 清空终点箱，或断开红石 |
| 物品走到半路掉在地上 | 走到了死路 | 顺着线找断开的地方，补上管道 |
| | 超过 64 格 | 阀门后第一格换成下界合金管道，或加一个中转箱重新出发 |
| | 终点箱满了 | 加箱子，或用填充机群、平衡分流器 |
| 物品跑进了旁边那条线 | 两条同颜色管道贴在一起 | 把其中一条换成别的颜色（A/B/C/D） |
| 分叉处有时往这边、有时往那边 | 普通岔路是随机的 | 换成分流器或过滤器 |
| 过滤器没有分拣 | 直走方向或侧面没接管道；样品和实际物品不是同一种 | 检查两边管道；魔法物品要放同一种魔法物品当样品 |
| 物品送不进熔炉 | 熔炉不是管道支持的容器 | 先送进漏斗，漏斗再往下送进熔炉 |
| 末影接口不传 | 频道名不一致；不在同一世界；超过 50 格；两端没贴容器 | 右键两端核对频道名，确认距离 |
| 填充机不装箱子 | 群超过 16 个方块；型号不一致；核心被红石充能 | 拆小群、统一型号、断开红石 |

还是解决不了？在[芸集知识之书](/linsmagic/atlas/guide/book)里点「反馈 bug 与提供更新建议」，写清楚坐标和现象。
