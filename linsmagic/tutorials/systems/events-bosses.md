# 夜间事件与首领

服务器的夜晚并不太平：随时可能出现血月、金耀之月等**特殊夜晚**；每隔一段时间还会有**精英怪**从天而降。这些事件较为危险，但许多高级材料只能从中获取。玩家也可以在**召唤祭坛**上主动召唤首领。

本篇介绍各类事件发生时的应对方式、可获得的材料以及主动触发的方法。

## 第 1 节：六种特殊夜晚 {#s-nights}

主世界入夜时有概率成为特殊夜晚，聊天栏会进行公告，天空与怪物外观也会发生变化。大多数特殊夜晚分为多个等级，等级越高越危险，掉落也越好。

| 夜晚 | 危险 | 事件内容 | 可获得 |
| --- | --- | --- | --- |
| [血月](/linsmagic/atlas/events/blood-moon)（I～IV 级） | ★★★★ | 刷怪量为 5～7 倍，怪物更强。IV 级带有飞行惩罚与杀戮惩罚，并会刷出血月坚守者 | 糜烂血魂石、月之碎阙、血腥残片等，IV 级才有「血灼的纯粹恶意」 |
| [爆破狂欢之夜](/linsmagic/atlas/events/explosion-carnival)（I～II 级） | ★★★ | 大量苦力怕与闪电苦力怕 | 爆燃绿硝、聚爆雷管、狂欢之星 |
| [暴食症象限之夜](/linsmagic/atlas/events/gluttony-quadrant)（I～III 级） | ★★ | 所有玩家持续饥饿，食物消耗极快 | 腐食涎液、噬食毒牙、暴食魔药 |
| [金耀之月](/linsmagic/atlas/events/golden-moon)（I～VIII 级） | ★★ | 金甲怪物军团，等级越高越强 | 月夜金箔、金粉……金砧，可出售给异界行商 |
| [星星之夜](/linsmagic/atlas/events/starry-night)（I～IV 级） | ★★ | 发光怪物数量增加、实力增强；失落废墟都市的陨石坠落概率提高至 2.5 倍 | 琉璃星星凝晶，用于制作粒子特效 |
| [和平之夜](/linsmagic/atlas/events/peaceful-night)（I～III 级） | 无 | 所有维度均不刷怪，玩家获得增益 | 无特殊掉落，适合安心建筑 |

<figure class="lm-shot"><img src="/linsmagic/tutorials/blood-moon-mobs.webp" alt="血月之夜：月亮与平时相同，但地面上的怪物数量是平时的数倍。" loading="lazy" /><figcaption>血月之夜：月亮与平时相同，但地面上的怪物数量是平时的数倍。</figcaption></figure>

::: danger 遇到 IV 级血月
- **飞行惩罚**：警告倒计时结束时，若玩家不在地面、水中或梯子藤蔓上（飞行、鞘翅滑翔均算在内），将被直接处死。
- **杀戮惩罚**：每击杀一只怪物，血月坚守者会在玩家身后刷新并发起攻击。
- 若不打算正面应对，可**直接前往下界或末地**躲过这一夜，特殊夜晚仅影响主世界。血月中掉落、损坏的物品一般不予补偿。
:::

::: tip 每种夜晚的专属材料
爆破狂欢、暴食、金耀之月中，每种怪物各有两种专属掉落，一种约 25%，一种约 12%；血月则为血月怪物统一的掉落。这些材料是催化剂、词条刻刀提取及许多装备的原料。完整列表请查看各夜晚的资料页。

获得这些掉落时聊天栏会有提示，觉得刷屏可在大典「个人设置 → 通用」中关闭「夜晚事件掉落提示」，与普通的「掉落物提示」分开设置。
:::

::: warning 驱魔灯在特殊夜晚失效
<LmItem id="驱魔灯核心" /> 在和平之夜以外的特殊夜晚期间只阻止幻翼，不再阻止其他怪物生成，详见[宁夜灯与驱魔灯核心](/linsmagic/atlas/tutorials/systems/multiblock#s-ward)。
:::

## 第 2 节：主动召唤特殊夜晚 {#s-summon}

如需刷取某种夜晚的材料，无需等待，可使用催化剂主动召唤：

| 道具 | 效果 | 来源 |
| --- | --- | --- |
| <LmItem id="罐装血契" /> | 随机 I～III 级血月 | 异界行商，或合成 |
| <LmItem id="罐装血珀" /> | III 级血月 | 异界行商，或合成 |
| <LmItem id="狂欢催化剂" /> | 随机 I～II 级爆破狂欢之夜 | 狂欢夜掉落合成 |
| <LmItem id="暴食催化剂" /> | 随机 I～III 级暴食症象限之夜 | 暴食夜掉落合成 |
| <LmItem id="金耀催化剂" /> | 随机 I～III 级金耀之月 | 金耀之月掉落合成 |

使用规则：

- 仅可在**主世界的夜晚**使用，且当前**没有**正在进行的特殊夜晚。
- 所有催化剂**全服共享冷却**，默认为现实时间 60 分钟。一名玩家使用后，其他玩家需等待冷却结束。
- 条件不满足或处于冷却中时使用，**不会消耗物品**。

催化剂会影响全服的夜晚，使用前请在聊天栏告知其他玩家。

## 第 3 节：精英怪 {#s-elite}

- 每隔约 **30 分钟**，会有一只精英怪降落在某位在线玩家附近的地表，并进行全服公告。
- 精英怪共 9 种，各自拥有独特的属性与粒子效果。击杀后有 **30%** 概率掉落对应的「核心」：

| 精英怪 | 核心 |
| --- | --- |
| 树精骷髅 | <LmItem id="自然核心" /> |
| 坚石僵尸 | <LmItem id="坚石核心" /> |
| 地狱焦炎烈焰人 | <LmItem id="焦炎核心" /> |
| 深海怨念溺尸 | <LmItem id="潮汐核心" /> |
| 末影虚空使者 | <LmItem id="虚空核心" /> |
| 瘟疫剧毒洞穴蜘蛛 | <LmItem id="剧毒核心" /> |
| 幻影狂风恶灵 | <LmItem id="狂风核心" /> |
| 极寒冻土流浪者 | <LmItem id="霜冻核心" /> |
| 枯萎凋零亡灵 | <LmItem id="凋零核心" /> |

- 如需立即挑战，可在异界行商处购买 <LmItem id="精英怪异饵料" />（目标为随机一名在线玩家）或 <LmItem id="精英怪异信息素" />（目标为自己），右键使用。附近没有开阔地表时召唤会失败，**不会消耗物品**，请更换至可直接看到天空的位置后重试。两者均有 5 秒冷却。
- 挂机时出现的精英怪不便寻找，可使用 <LmItem id="精英怪追踪器" />：右键指向同一世界 1000 格内最近的精英怪，聊天栏显示距离、方向与高度。精英怪所在区块未加载时，指向它最后出现的位置。冷却 10 秒，不消耗。

## 第 4 节：召唤首领 {#s-boss}

### 召唤祭坛

<AtlasRecipe id="legacy-590f3349fdb0" />

1. 使用 4 块錾制石砖合成 <LmItem id="召唤祭坛" />，在开阔的场地放置。
2. 将某个首领的**全部召唤材料放入背包**（无需手持）。
3. **右键祭坛**，材料将被扣除，首领在祭坛上方降临。

::: warning 背包里只带一个首领的材料
祭坛按下表**顺序**检查背包，满足哪个首领的材料即召唤哪个首领。例如想召唤僵尸统帅时，若背包中恰好也有 2 个铁块与 4 个铁锭，则会优先召唤排在前面的铁傀儡·异化。召唤前请将其他首领的材料存入箱子。
:::

- 祭坛 100 格范围内已有首领正在战斗时，无法再次召唤。
- 首领实力较强，建议组队挑战，备好药水与食物，并避免在基地中召唤。

## 第 5 节：其他全服事件 {#s-other}

- **[全服增益](/linsmagic/atlas/events/server-buffs)**：随机刷新晴天、雨天、雷暴、双倍经验、双倍掉落，持续 30 分钟；也可使用对应的「水晶」主动开启。双倍掉落仅翻倍怪物的**原版**掉落与经验，魔法材料不会翻倍。
- **[异界行商收购新品](/linsmagic/atlas/events/merchant-purchases)**：行商会临时高价收购某种材料，持续 5～45 分钟，请留意公告。
- **[虚空低语](/linsmagic/atlas/events/void-whispers)**：每隔一段时间玩家会收到一张随机的配方图纸，有助于发现尚未见过的物品。
- **[全服通告](/linsmagic/atlas/events/server-announcements)**：有玩家贡献大典、附魔出顶级附魔或获得极其稀有的物品时，全服玩家均可看到。
