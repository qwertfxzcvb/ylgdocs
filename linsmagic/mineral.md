# 工业矿机组

> [!IMPORTANT]
> 工业矿机组是获取[矿砂](/linsmagic/merchant)的重要物品。

## 获取
**矿机基座、维度探针、挖掘模块**
- 合成配方请自行查询[芸集知识之书](/linsmagic/book)
## 使用指南
### 矿机基座
![示例](/linsmagic/mineral0.png)
::: tip 小贴士
- 燃料为`任意木板`，无法自动填充。
:::
- 放置后，中枢全息影像将会在矿机上方自动开启(可切换显示)
![示例](/linsmagic/mineral1.png)
- 放入燃料后，点击`开始挖掘`开始生产矿砂，燃料不足、储存满或到达一定时间后将自动停止。
### 维度探针
- 将维度探针放在矿机周围(1格内，Y相同)，矿机会自动读取。
![示例](/linsmagic/mineral5.png)
::: warning 提示
- 星辉级至混沌级矿砂需使用`恒温箱`储存，创世级及以上等级矿砂需使用`致密恒温箱`储存，否则将转化为`原矿废料`
:::
::: tip 小贴士
- 漏斗、潜影盒等容器也可以保存高级矿砂
- 维度探针无需升级，可以直接制作高等级的探针
:::
### 挖掘模块
- 挖掘模块有`基础挖掘模块`和`标准挖掘模块`两类。
![示例](/linsmagic/mineral2.png)![示例](/linsmagic/mineral3.png)
- 放置在矿机附近(1格内，Y相同)，矿机会自动读取并同步速度。
![示例](/linsmagic/mineral4.png)
