# 芸集知识之书
![示例](/linsmagic/book0.png)
> [!IMPORTANT]
> 芸集知识之书是本服的重要物品，可在其中查询到所有魔法物品的获取方法及其配方，同时包含多种魔法菜单和功能开关。

## 获取

```
/lm book
```

- 输入该指令，服务器会给予你一本`芸集知识之书`（`/book` 也可使用）。
![示例](/linsmagic/book1.png)
::: tip 小贴士
- 当你的背包中不存在芸集知识之书时，服务器每过一段时间将会提示你。
- 该提示可通过 **/linsmagic info on/off** 来开启/关闭。
:::

## 功能大全
![示例](/linsmagic/book2.png)
- **非图鉴类**

| 功能 | 说明 |
|------|------|
| **个人设置** | 可配置插件部分内容。 |
| **大典荣誉成就(个人/排行榜)** | 鼠标光标移至**个人设置**上方即可查看，可查看魔法物品贡献值。 |
| **反馈&建议** | 反馈bug、提供更新建议。 |
| **公会大厅** | 详见[工会](/linsmagic/guild)。 |
| **异界行商联络器** | 详见[异界行商联络器](/linsmagic/merchant)。 |
| **次元枢纽** | 详见[次元枢纽传送单元](/linsmagic/hub)。 |

- **图鉴类**

| 功能 | 说明 |
|------|------|
| **铁路工具** | 铁路相关的机器方块与高速矿车。 |
| **魔法红石科技图鉴** | 查看全服所有红石科技机械与逻辑电路结构。 |
| **繁星粒子魔法图鉴** | 记载星星之夜(详见[夜晚](/linsmagic/night))诞生的琉璃凝晶与繁星魔法科技。 |
| **暮光机器** | 使用非常规操作模式。 |
| **魔法机械结构图鉴** | 展示全服所有需要特定空间摆放的大型多块魔法机器结构。 |
| **魔法附魔图鉴** | 罗列了全服所有注魔/高级附魔。 |
| **首领图鉴** | 记载全服所有可召唤首领的信息，需使用`召唤祭坛`进行召唤 |
| **配方向导** | 进入菜单后可在空格处放置想要查询的材料查询其信息与合成配方。 |
| **魔法图鉴大典** | 罗列了全服所有魔法物品。 |
| **魔法合成大典** | 罗列了全服所有可合成的魔法物品。 |
