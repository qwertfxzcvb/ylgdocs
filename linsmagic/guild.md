# 工会
![示例](/linsmagic/guild0.png)
> [!IMPORTANT]
> 服务器为玩家联盟提供了工会功能，让玩家能更加清晰了解服务器各个势力。

## 界面
![示例](/linsmagic/guild1.png)
```
/guild
```

- 输入该指令，会打开工会列表界面
- 你可以在该界面申请加入公会、创建公会和查看工会排名。
::: tip 小贴士
- [芸集知识之书](/linsmagic/book)中包含了该菜单。
:::


## 工会排名
![示例](/linsmagic/guild2.png)
- 工会排名按照`魂契值`进行排序，在菜单中献祭魂石以获取魂契值。
::: tip 小贴士
- 魂石可通过**击杀全服任何生物**掉落，概率为2%。
:::

## 工会增益

在 `/guild` 的本公会详情中选择「兑换工会增益」，可使用公会共有的魂契值兑换持续增益。只有会长和副会长可以确认兑换，普通成员可以查看增益与费用。

- 增益需要逐级兑换，各级费用分别支付；高等级替换低等级，不重复叠加。
- 已兑换增益对本公会成员生效，每秒同步一次。退出公会后不再获得该公会的增益。
- 增益页面右下方的「接收工会增益」开关只影响自己，不影响其他成员，也不会取消公会已兑换的等级。
- 同类效果已有更高等级时，公会增益不会将其降低。攻击伤害直接增加对应数值；生命提升每级增加 4 点生命上限。

| 增益 | 各级魂契值费用（按 I → 最高级排列） |
|------|------|
| 速度 I～II | 4,320 / 19,280 |
| 跳跃提升 I～II | 2,000 / 8,000 |
| 力量 I | 98,000 |
| 抗性提升 I | 12,000 |
| 急迫 I～III | 120 / 6,980 / 73,000 |
| 生命恢复 I～III | 900 / 40,000 / 120,000 |
| 幸运 I～III | 120 / 240 / 1,640 |
| 抗火 I | 27,000 |
| 生命提升 I～V | 1,240 / 40,213 / 454,000 / 860,000 / 6,790,000 |
| 水下呼吸 I | 64 |
| 夜视 I | 64 |
| 攻击伤害 +1～+3 | 58,000 / 132,018 / 618,000 |

::: tip 提示
兑换消耗的魂契值会从公会余额中扣除，因此也会影响按魂契值排列的工会排名。兑换前请核对确认页面的效果和费用。
:::
