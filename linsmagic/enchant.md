# 分类
### 注魔附魔
![示例](/linsmagic/enchant1.png)
- 注魔附魔包含6类，每类包含3种注魔，每种注魔对应不同效果、适配不同装备。
- 注魔等级一般为I-III级，少部分为II级。
- 获取注魔附魔需按照`魔法机械结构图鉴`中**附魔注魔器**的搭建方法正确注魔后才会有概率出现。
::: tip 小贴士
- 注魔附魔使用附魔台中的1、2级附魔也有概率出现。
- 附魔出最高级注魔时，将会进行[全服通告](/linsmagic/special)。
- 注魔时附魔台有概率爆炸。
:::
### 高级附魔
![示例](/linsmagic/enchant2.png)
- 高级附魔有5个等级，每个等级包含若干种附魔，每种附魔对应不同能力、适配不同装备。
- 高级附魔等级有I-X级不等，详情请自行查询[芸集知识之书](/linsmagic/book)。
- 高级附魔无需注魔器，普通附魔台即可获取高级附魔。
::: tip 小贴士
- 高级附魔必须使用附魔台中的3级附魔才有概率出现。
- 附魔出史诗/传奇附魔时，将会进行[全服通告](/linsmagic/special)，无论等级。
:::
