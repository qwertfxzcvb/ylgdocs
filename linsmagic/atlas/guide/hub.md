# 次元枢纽传送单元
![示例](/linsmagic/hub0.png)
> [!IMPORTANT]
> 次元枢纽传送单元可以让你传送至其他魔法世界/回到主世界。

## 获取

```
/hub
```

- 输入该指令，服务器会给予你一个`次元枢纽传送单元`。
![示例](/linsmagic/hub1.png)
::: tip 小贴士
- [芸集知识之书](/linsmagic/atlas/guide/book)中包含了该物品菜单，无需重复获取。
:::

## 次元枢纽传送系统
![示例](/linsmagic/hub2.png)
| 世界名称 | 世界说明 |
|------|------|
| **亚元中古世界** | 该世界包含多种特殊地形，玩家可在此收集一些三大维度不易收集的物品。 |
| **荒凉混凝土世界** | 该世界由各色混凝土/混凝土粉末组成，可在其中收集混凝土类物品。 |
| **回到主世界** | 回到主世界主城位置。 |
::: tip 小贴士
- 魔法世界与主世界时间、天气均不同，同时[特殊夜晚](/linsmagic/atlas/guide/night)也无法影响到魔法世界。
:::
