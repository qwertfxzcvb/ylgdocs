# 特殊夜晚(图片待补充)

- 服务器的夜晚会随机触发特殊事件。
- 不同类型的夜晚，怪物有不同的特殊掉落物。
- 可用对应催化剂主动召唤部分事件：只能在主世界夜晚使用，已有特殊夜晚时不能使用；所有催化剂共享全服冷却（默认现实时间 60 分钟）。召唤失败或冷却中不会消耗物品。

::: tip 提示
- 括号内第一个数据为基础出现概率
- 以后每级出现概率为第一个数据乘第二个数据的n-1次方
:::

## **1. 血月(5%,5%)**
| 等级 | 说明 |
|------|------|
| **I级** | 怪物们的狂热复仇，刷怪量提高5倍，怪物伤害有所提升。 |
| **II级** | 怪物们的狂暴复仇，刷怪量提高5倍，怪物伤害有所提升。 |
| **III级** | 怪物们的终极复仇，刷怪量提高5倍，怪物伤害有所提升。 |
| **IV级** | 终焉已至，刷怪量提高7倍，刷新血月坚守者等顶级怪物，击杀任何生物都会掉落特殊物品`血灼的纯粹恶意`。 |
::: warning 提示
- IV级血月拥有**飞行处罚**及**杀戮惩罚**。
- 警告倒计时结束仍然处于悬浮状态时，将被**杀死**。
- 进行击杀后，**血月坚守者**将会刷新在玩家身后并攻击。
:::
::: danger 警告
- I-III级血月相对简单，但仍需注意装备耐久。
- 若遭遇IV级血月，无需求建议**立刻离开你的基地**并前往**下界或末地**进行规避。
- 无特殊情况，所有在血月中掉落/损坏的物品均**不予补偿**。
:::
::: tip 小贴士
- 若出现 **血月被中止，黑暗渐渐褪去……** ，则说明管理员跳过了该次事件。
- 可在[异界行商面板](/linsmagic/atlas/guide/merchant)中购买[罐装血契](/linsmagic/atlas/items/tools/i-67f9c39e2c78)或[罐装血珀](/linsmagic/atlas/items/tools/i-8163ff2f2450)主动召唤血月。血契随机召唤 I～III 级，血珀召唤 III 级。
:::

## **2. 爆破狂欢之夜(5%,30%)**
| 等级 | 说明 |
|------|------|
| **I级** | 怪物们点燃了狂欢的引信/怪物们的狂轰滥炸之夜/刷怪将如烟花般炸裂开来。 |
| **II级** | 同I级 |
::: warning 提示
- 该事件下大量刷新**爬行者**和**闪电爬行者**
- 若你的建筑无领地保护，建议尽快远离它
- [狂欢催化剂](/linsmagic/atlas/items/tools/i-0df8eee10af7)可主动召唤随机 I～II 级爆破狂欢之夜。
:::

## **3. 暴食症象限之夜(5%,30%)**
| 等级 | 说明 |
|------|------|
| **I级** | 贪食的阴影笼罩了大地！你将获得饥饿效果。|
| **II级** | 贪食的饥渴愈发难耐……你将获得饥饿效果。 |
| **III级** | 无人能逃离这永不满足的食欲！你将获得饥饿效果。 |
::: tip 小贴士
- 该事件下食物消耗量极高
- 无必要不建议进行工作
- [暴食催化剂](/linsmagic/atlas/items/tools/i-18566546d3f7)可主动召唤随机 I～III 级暴食症象限之夜。
:::

## **4. 和平之夜(5%,20%)**
| 等级 | 说明 |
|------|------|
| **I级** | 温柔的月光抚平了黑夜的躁动，今晚没有怪物会来打扰…… |
| **II级** | 和平的气息愈发浓郁，玩家们在温柔夜色中感到无比安宁！ |
| **III级** | 极致的和平降临，温暖的圣光包裹着每一位玩家！ |
::: tip 小贴士
- 该事件下**所有维度**均不会**刷新任何怪物**，玩家获得的增益效果随等级递增。
- 该事件无特殊掉落物。
:::

## **5. 星星之夜(5%,20%)**
| 等级 | 说明 |
|------|------|
| **I级** | 璀璨的星尘洒满夜空，怪物们在星光下变得狂暴！ |
| **II级** | 星光愈发炽烈，更多怪物在星辉中熠熠生辉！ |
| **III级** | 漫天星雨倾泻而下，繁星之力笼罩了整片天地！ |
| **IV级** | 最极致的流星爆发！所有怪物都将沐浴在辉煌的星光之中！ |
::: tip 小贴士
- 该事件下所有**发光怪物**均有60%概率掉落**琉璃星星凝晶**
- 可通过`繁星魔法机器`对掉落物加工，自定义想要的粒子效果
:::
