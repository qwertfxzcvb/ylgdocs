# 特殊事件

为丰富玩法和玩家体验，服务器提供了丰富的特殊事件。

## 精英怪
![示例](/linsmagic/special1.png)
- 每过一段时间会有随机精英怪随机降落在目前在线玩家附近。
- 也可以使用异界行商面板中购买的`精英怪异饵料`和`精英怪异信息素`手动召唤。
- 击败精英怪后有**特殊掉落物**。

## 异界行商收购新品
![示例](/linsmagic/special2.png)
- 异界行商每过一段时间就会收购随机物品，你可以出售这些物品获取金币。
- 需配合[异界行商面板](/linsmagic/atlas/guide/merchant)使用。

## 全服增益
![示例](/linsmagic/special3.png)
服务器会随机刷新增益，玩家也可通过使用魔法物品来召唤增益。


| 增益 | 说明 |
|------|------|
| **晴天** | 增益持续时间内，天气恒为晴天。 |
| **雨天** | 增益持续时间内，天气恒为雨天。 |
| **雷暴** | 增益持续时间内，天气恒为雷暴。 |
| **双倍经验** | 增益持续时间内，所有经验掉落均为双倍。 |
| **双倍掉落** | 增益持续时间内，所有物品掉落均为双倍。 |

## 虚空低语事件
![示例](/linsmagic/special8.png)
