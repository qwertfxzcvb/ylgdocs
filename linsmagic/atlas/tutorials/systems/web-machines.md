# 网页机器教程

「网页机器」是能和网站联动的机器：在游戏里拿一个一次性密钥，到网页上操作，结果再回到游戏里。现在最实用的是 **绘制台-WE**，它能把任意图片做成挂在墙上的地图画。

## 绘制台-WE：图片变地图画 {#s-drawing}

### 做一台

材料全是原版物品：纸、墨囊、工作台、制图台、铁块和铁砧。

<AtlasRecipe id="drawing_table_we" />

### 使用步骤

1. 放下 <LmItem id="绘制台-WE" />，**右键**打开界面。
2. 点中间的「获取绘制台-WE密钥」。聊天栏会给出一串密钥（**点击就能复制**）和网页地址 [machine.ylg.net.cn/canvas](https://machine.ylg.net.cn/canvas)。
3. 打开网页，粘贴密钥，点「进入」。
4. 在编辑器里画图，或者点「导入图片」上传一张图片。也可以直接 `Ctrl+V` 粘贴剪贴板里的图片。
   - **抖动**：「弗洛伊德」「阿特金森」「有序」会用点阵模拟更多颜色，照片类图片选弗洛伊德效果通常最好；像素画、图标选「无」。
   - 画笔、橡皮、填充、取色、直线、圆、矩形都能用来修图，`Ctrl+Z` 撤销。
5. 点「发送地图」。回到游戏，聊天栏提示完成后，**再右键刚才那台绘制台**，从输出格取出地图画。如果那台绘制台已经不在了，地图会直接进背包，背包满了就掉在脚边。
6. 把地图放进物品展示框挂到墙上。

::: tip 密钥规则
- 每个密钥**只能用一次**，默认 24 小时后失效。想再画一张，就回绘制台重新获取。
:::

### 常见问题

| 现象 | 原因 | 怎么办 |
| --- | --- | --- |
| 点按钮后提示「密钥生成失败」 | 网页服务暂时连不上 | 过一会再试；持续失败请反馈给管理员 |
| 网页提示密钥无效 | 已经用过，或超过 24 小时 | 回绘制台重新获取 |
| 发送后游戏里没收到 | 网页和服务器之间有几秒延迟 | 保持在线等一会；再右键绘制台看输出格 |
| 颜色和原图差很多 | 地图只有有限的几十种颜色 | 换一种抖动方式，或先把图片调亮、提高对比度 |

## PyCo30 操作仪 {#s-pyco30}

<LmItem id="PyCo30操作仪" /> 是 PyCo30 系列网页操作台的初代机，用法和绘制台一样：放下后右键获取一次性密钥，按提示进入网页端。它的网页功能**还在开发中**，目前只能做连通测试，暂时不必专门去做。材料要 Py、Co 回路钢块等高级材料，点资料页可以看完整合成树。
