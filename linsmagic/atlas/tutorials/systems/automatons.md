# 自动机器（LanT-Flow）

LanT-Flow 系列是可编程的双轮自动机：放置机器方块后，旁边会出现一台机器人，按你编写的程序逐步行动——行走、转向、搬运方块、从箱子取货、送货入库。程序有两种写法：

- **格子程序**：在游戏内的程序面板里逐格点选指令，适合简单的往返与巡逻。
- **LanT 脚本**：一种简单的指令语言，支持循环、条件判断与跳转，可在网页编辑器里用积木或代码编写。

## 最小例子：让机器人来回巡逻 {#s-first}

1. 放置机器方块，机器人会出现在方块上方，面朝放置时你所面对的方向。
2. 在机器方块旁放一根**拉杆并打开**。机器方块必须有红石信号才会执行程序，关掉拉杆即可暂停，再次打开会从暂停处继续。
3. 右键机器方块打开程序面板（潜行右键则可以贴着机器方块放置方块）。
4. 依次点击前几个格子，选择「前进一格」×3、「右转 90°」×2，第 6 格以后留空。
5. 机器人每秒读取一格：前进三格后掉头，空格也会占用一秒，读完最后一格后从第 1 格重新开始。

面板上正在等待执行的格子会**发光**，并标有「▶ 下一步执行这一格」，可以直观看到程序进行到哪里。

## 程序面板 {#s-panel}

| 按钮 | 作用 |
| --- | --- |
| 程序格 | 点击后选择指令；带参数的指令（取物数量、跳转格号、坐标等）会打开设置菜单 |
| 指针回到第 1 格 | 下一步从第 1 格开始执行，进行中的等待、走到坐标与循环计数一并清零 |
| 清空全部程序 | 需按住 Shift 点击，防止误操作 |
| 写入 / 读取程序卡 | 见[程序卡](#s-card) |
| 切换到脚本模式 | 改用 LanT 脚本；尚未编写脚本时，会自动把当前格子程序转换为脚本 |
| 网页编辑 | 生成网页编辑器密钥，见[网页编辑器](#s-web) |

设置菜单中的数字（取物数量、跳转格号、等待秒数、循环遍数、目标坐标）都可以**点击后在聊天栏直接输入**；坐标还可以一次输入「X Z」，或照抄 F3 中的「X Y Z」。「走到坐标」菜单中的「填入我脚下的坐标」会把目标设为你当前站立的方块，先走到目的地再用遥控器打开面板设置最为方便。

### 格子指令一览

| 指令 | 说明 |
| --- | --- |
| 前进一格 / 后退一格 | 一格以内的台阶会自动迈上；被墙挡住时原地不动，记为失败 |
| 右转 90° / 左转 90° | 原地转向 |
| 转向方向 | 直接转到东、南、西、北中的指定方向 |
| 走到坐标 | 先沿 X、再沿 Z 走到目标方块坐标，到达后转回出发时的朝向；连续 5 次被挡住则放弃，记为失败 |
| 拿起脚下方块 | 把脚下的完整方块举在身前 |
| 放下方块于脚下 | 把举着的方块放在脚下并站上去 |
| 箱子取物 | 从脚下或正面的箱子、木桶中取出指定物品；不可堆叠的物品一次只取 1 个 |
| 放进箱子 | 把手上的东西放入脚下或正面的箱子，能放多少放多少 |
| 向下扔出 | 把手上的东西整叠扔向正下方，下方的漏斗可以接住 |
| 等待 | 原地停留 1～600 秒 |
| IF 判断 | 条件不成立时跳到指定格；条件见下表 |
| 回到指定格 | 无条件跳到指定格 |
| 循环 | 让指定格到本格之间的程序重复执行若干遍 |

IF 判断可用的条件：脚下方块是否为指定方块、手上是否拿着物品 / 方块 / 任意东西、上一格是否执行成功、机器人所在位置是否有红石信号、脚下或正面的箱子是否已满 / 已空。

## LanT 脚本 {#s-script}

当程序需要「重复到箱子装满为止」「被挡住就绕路」这类逻辑时，脚本比格子更方便。一行一条指令，`#` 之后是注释：

```text
# 在仓库与矿场之间往返运送圆石
face north
repeat 10
  take cobblestone 64
  if not ok
    stop              # 箱子空了就停机
  end
  moveto 120 -60
  while holding and not chest full
    store
  end
  moveto 120 -39
end
```

| 语句 | 写法 |
| --- | --- |
| 移动 | `forward [格数]`、`back [格数]`、`left`、`right`、`face north/east/south/west`、`moveto X Z` |
| 手上与箱子 | `pick`、`place`、`throw`、`take 物品 [数量]`、`store` |
| 时间 | `wait 秒` |
| 循环 | `repeat 次数 … end`、`loop … end`（无限循环）、`while 条件 … end` |
| 判断 | `if 条件 … elif 条件 … else … end` |
| 流程 | `break`（跳出循环）、`continue`（进入下一轮）、`stop`（停机）、`label 名称` / `goto 名称` |

| 条件 | 含义 |
| --- | --- |
| `blocked` | 正前方无法通行（墙、未加载的区块或其他领地） |
| `ok` | 上一个动作是否成功 |
| `power` | 机器人所在的格子或脚下方块有红石信号 |
| `holding [item/block/any]` | 手上拿着物品 / 方块 / 任意东西 |
| `below 方块`、`front 方块` | 脚下 / 正前方的方块是否为指定方块 |
| `chest full`、`chest empty`、`chest has 物品` | 脚下或正面的箱子已满 / 已空 / 含有指定物品 |

条件可以用 `not` 取反，用 `and`、`or` 组合，也可以加括号。物品写原版英文 ID（如 `cobblestone`、`oak_log`），插件物品写作 `id:物品名`（如 `id:风雷剑`）。

执行规则：

- 每个节拍执行一个**动作**；判断、跳转等流程语句不占用时间。
- 读完最后一行后从第一行重新开始；需要停下时写 `stop`，之后在面板点击「从第 1 行重新开始」即可再次运行。
- 脚本最多 300 行。

### 在游戏中查看与导入

- 脚本模式下，面板的每一格显示一行代码，正在执行的那一行会发光；点击任意一行，可以书本形式查看全部代码。
- **书与笔导入**：把代码写在书与笔（或成书）里，主手拿着书，在脚本面板点击「从手中的书导入」。各页按顺序拼接成脚本，书不会被消耗；如有语法错误，聊天栏会列出出错的行号与原因，不会导入。

## 网页编辑器 {#s-web}

网页编辑器提供积木与代码两种编辑方式，两者实时同步：

1. 在程序面板点击「网页编辑」，聊天栏会显示一次性密钥（点击可复制）和网页链接。
2. 点击链接打开 [machine.ylg.net.cn/robot](https://machine.ylg.net.cn/robot)，密钥会自动填入；也可以手动输入。
3. 进入后，左侧是积木库，中间是积木，右侧是代码：
   - 从积木库拖动积木到程序中，或点击积木插入到选中积木之后；积木可以拖动排序、嵌套进循环与判断。
   - 在代码中输入指令首字母即可补全，物品可以用英文 ID 或中文名搜索；鼠标悬停在指令上可查看说明。
   - 错误会实时标出，并显示在「问题」面板中，修正后才能上传。
4. 点击「上传到机器」，机器会在几秒内载入新脚本，切换为脚本模式并从第 1 行开始执行，你会在聊天栏收到提示。

::: tip 密钥规则
- 每个密钥只能进入一次，默认 24 小时后失效；在同一个浏览器标签页里刷新不需要重新输入。
- 重新生成密钥后，旧密钥上传的脚本不会再被机器接收。
- 编辑中的内容会自动保存在本机浏览器，下次用同一台机器的密钥进入时可以恢复。
:::

## 程序卡 {#s-card}

<LmItem id="自动机程序卡" /> 可以保存一台机器当前模式下的程序（格子程序或脚本），再载入到其他机器：

- 「写入程序卡」使用主手中的卡，主手没有时使用背包中的第一张；一叠卡只会写入其中一张。
- 「读取程序卡」会覆盖目标机器的程序。读取格子程序时，超出该机器格数的格子以及该型号不支持的指令会被跳过，聊天栏会提示跳过的数量。

## 领地规则 {#s-residence}

- 机器方块放在领地内：机器人可以在该领地内自由活动，也可以离开领地，但**不能进入其他领地**，也不能操作其他领地里的方块和箱子。
- 机器方块放在领地外：机器人不能进入任何领地。
- 打开程序面板（包括用遥控器远程打开）需要机器方块所在位置的箱子使用权限。

## 常见问题 {#s-faq}

| 现象 | 原因 | 解决方法 |
| --- | --- | --- |
| 机器人不动，头顶显示「缺红石信号」 | 机器方块没有红石信号 | 在机器方块旁放置拉杆并打开，或用红石块、红石线供能 |
| 头顶显示「脚本有错误」 | 脚本中有语法错误 | 打开面板查看出错的行，或在网页编辑器中修正后重新上传 |
| 头顶显示「程序已结束」 | 脚本执行到了 `stop` | 在面板点击「从第 1 行重新开始」 |
| 走到坐标中途停下并继续执行下一步 | 连续 5 次被挡住，已放弃本次移动 | 清除路上的障碍，或用 `if not ok` 编写绕路程序 |
| 取物没有反应 | 脚下和正面都没有箱子，或箱子中没有指定物品 | 让机器人站在箱子上或面对箱子；检查物品写法是否正确 |
| 机器人在其他领地边界前停住 | 机器人不能进入其他领地 | 调整路线，或把机器方块放在要活动的领地内 |
| 网页提示密钥无效 | 密钥已使用或已超过 24 小时 | 回到程序面板重新点击「网页编辑」 |
| 上传后机器没有变化 | 网页与服务器之间有数秒延迟 | 稍等片刻；若聊天栏提示脚本有错误，按提示修正后重新上传 |
| 遥控器对空右键没有反应 | 遥控器尚未绑定机器 | 手持遥控器右键机器方块进行绑定 |
