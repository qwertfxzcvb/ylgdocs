# 应用能源教程（自动合成）

ME 网络可以按照「样板」中记录的配方自动合成物品：在终端中对可合成物品 Shift+右键下单，网络会计算所需材料，交由合成 CPU 调度，由分子装配室或其他机器执行，完成后产物回到网络。

阅读本篇前，请先完成[应用能源（入门）](/linsmagic/atlas/tutorials/systems/applied-energistics)，确保已有一个能正常存取物品的网络。

## 第 1 节：编写样板 {#s-pattern}

<LmItem id="ME样板编码终端" /> 上方显示网络中的物品，下方为配方格。配方格为「幻影格」，只记录物品种类与数量，**不消耗实物**。

### 合成样板

记录一条 3×3 工作台配方，由分子装配室执行。

- 右键上方的网络物品，可自动填入该物品的配方；多次右键可切换不同配方。
- 也可以手动点击网络物品，将其作为材料放入配方格。

### 处理样板

记录「任意输入 → 最多 3 种产出」，由样板供应器将原料推入贴着的机器，适用于熔炉烧炼、插件机器加工等工作台以外的加工。

- 数量调整：左键 +1、右键 -1、Shift+左键 +16，对格子按 Q 可输入精确数量，最多 4096。
- 示例：输入 1 个粗铁，产出 1 个铁锭，供应器贴着熔炉即可自动烧炼。

### 编码与修改

- 空白样板槽为空时，编码会自动从网络中取出空白样板。
- 将旧样板放入空白样板槽，可读出其内容后重新修改。
- 已编码样板手持**潜行右键空气**：清空为空白样板。
- 空白样板槽、成品槽与配方格的内容**保存在终端方块上**，关闭界面不会退还，其他玩家打开时也相同；拆除终端时样板会掉落。

## 第 2 节：样板供应器 {#s-provider}

<LmItem id="ME样板供应器" /> 有 9 个样板槽。放入样板后，终端中对应的物品即显示为「可合成」。

| 样板类型 | 执行方式 |
| --- | --- |
| 合成样板 | 交给网络中**任意**空闲的分子装配室执行，装配室**不必贴着供应器** |
| 处理样板 | 将原料推入供应器**贴着的**容器或机器：箱子、木桶等容器；压印器、充能器、晶体催化器；插件机器的输入口；**熔炉 / 高炉 / 烟熏炉**（原料进入烧炼格，样板中带燃料时燃料进入燃料格） |

### 处理样板的产物回收

处理样板的产物必须回到网络，任务才算完成：

- **熔炉、高炉、烟熏炉**：烧好的产物由供应器**自动收回**。
- **压印器、充能器、晶体催化器**：接入同一网络时，产物自动存入网络。
- **其他机器**：用管道将产物送回 <LmItem id="ME接口" />，或在机器的出货箱上安装 <LmItem id="ME输入总线" />。

::: tip 阻挡模式
供应器可开启「阻挡模式」：目标容器中还有上一批原料时，不推送下一批。适用于一次只能处理一组原料的机器，避免不同配方的原料混在一起。
:::

### 分子装配室

<LmItem id="分子装配室" /> 每次合成约 0.5 秒、消耗 50 AE；安装 1 / 2 / 3 / 4 张加速卡时分别为 0.25 / 0.15 / 0.1 / 0.05 秒（实际受合成调度每 0.25 秒一轮的限制）。放置多台即可并行合成。

## 第 3 节：合成 CPU {#s-cpu}

相连的 <LmItem id="合成单元" />、合成存储器与 <LmItem id="并行处理单元" /> 组成一台合成 CPU：

- **形状不限**，不要求长方体，但一台 CPU **至少需要一个合成存储器**。
- **容量**：合成存储器提供字节，下单时计算任务所需字节，自动选择容量最小且足够的空闲 CPU。
- **并行**：每 0.25 秒最多发出 `2 × (1 + 并行处理单元数)` 步，即每个并行处理单元 +2 步。
- 合成进行中，并行处理单元会亮起；CPU 最高处上方悬浮显示「合成 CPU #编号」、目标物品与数量、进度条、百分比与当前状态，空闲时只显示一行。
- 可放置多台 CPU，同时执行多个任务。

| 合成存储器 | 容量 |
| --- | --- |
| <LmItem id="1k合成存储器" /> | 1,024 字节 |
| <LmItem id="4k合成存储器" /> | 4,096 字节 |
| <LmItem id="16k合成存储器" /> | 16,384 字节 |
| <LmItem id="64k合成存储器" /> | 65,536 字节 |

## 第 4 节：下单与任务管理 {#s-order}

### 下单

1. 在终端中对可合成物品 **Shift+右键**，打开下单界面。
2. 界面会列出「使用库存」「需要合成」「仍缺少」三部分，确认材料充足后点击确认开工。
3. 开工时，所需的库存材料会先提入 CPU。
4. 合成完成后，下单玩家会收到消息与音效；产物与多余的中间产物回到网络。

合成完成通知可在芸集知识之书的**个人设置**中关闭（「应用能源」一行的「合成完成通知」）。

### 合成任务管理

终端中的「合成任务管理」按钮（鼠标悬停可查看正在合成的任务列表）：

- 列出所有 CPU：空闲或正在合成的物品、进度条、状态与下单人。
- 超过 60 秒没有进展的任务会标红，按钮图标变为红石块。
- **左键**：查看详情，包括等待返回的处理产物、CPU 中暂存的材料与剩余步骤。
- **Shift+右键两次**（或点击详情页右下角按钮两次）：取消任务，CPU 中暂存的材料全部退回网络。已推入机器的处理原料不会收回。
- 找不到所在 CPU 的任务（例如 CPU 被拆改后未能挂回）也会列出，可直接取消并退回材料。

## 第 5 节：自动补货 {#s-auto}

<LmItem id="合成卡" /> 可让设备在缺货时自动下单：

- **ME输出总线 + 合成卡**：需要导出的物品没有库存时，自动请求合成。
- **ME接口 + 合成卡**：备货不足时，自动请求合成。
- 同一台设备至少间隔 10 秒下单一次；同种物品已有任务时不会重复下单。
- 自动下单静默进行，完成时不提示。

::: tip 常见用法
接口备货 64 个某种材料并安装合成卡，再用传出阀从接口取货送往机器，即可实现「机器缺料时网络自动合成并补充」。管道对接方式见[入门篇第 6 节](/linsmagic/atlas/tutorials/systems/applied-energistics#s-bus)。
:::

## 第 6 节：无线终端 {#s-wireless}

<LmItem id="ME无线终端" /> 可随时随地访问网络：

1. 在网络中放置 <LmItem id="ME无线访问点" />。
2. 拿着无线终端**右键无线访问点**，完成绑定。
3. 之后在该网络**任意一个**无线访问点的 **48 格**范围内，右键空气即可打开终端。
4. 潜行右键空气：切换普通终端 / 合成终端模式。

- 电量上限 1600；每次打开消耗 2 点，打开期间每 10 秒消耗 1 点。
- 充电方式：放入红石充能桩（充能桩每点能量 = 25 点终端电量）或 <LmItem id="充能器" />。

## 常见问题 {#s-faq}

| 现象 | 原因 | 解决方法 |
| --- | --- | --- |
| 终端中物品不显示为可合成 | 样板未放入样板供应器，或供应器离线 | 将样板放入供应器；检查设备名额与电量 |
| 下单时提示仍缺少材料 | 网络中材料不足，且缺少对应样板 | 补充材料，或为缺少的中间材料编写样板 |
| 下单后没有 CPU 可用 | 没有合成 CPU，或 CPU 容量不足 / 全部忙碌 | 搭建 CPU（至少一个合成存储器），或增大合成存储器容量 |
| 合成样板一直不执行 | 网络中没有分子装配室 | 放置分子装配室并接入网络 |
| 处理样板的任务一直不完成 | 产物没有回到网络 | 熔炉类由供应器自动收回；其他机器用管道送回 ME接口，或在出货箱装输入总线 |
| 任务标红 | 超过 60 秒没有进展 | 在「合成任务管理」中查看详情，必要时取消任务退回材料 |
| 处理样板的原料没有推入机器 | 机器没有贴着样板供应器 | 将目标机器与供应器相邻放置 |
| 无线终端打不开 | 超出 48 格范围、未绑定或没电 | 靠近无线访问点；重新绑定；使用充能器或红石充能桩充电 |
