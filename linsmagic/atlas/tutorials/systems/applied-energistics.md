# 应用能源教程（入门）

「应用能源」是仿照 Applied Energistics 2 制作的 **ME 网络**系统：将物品存入存储元件，通过终端统一存取、搜索、自动合成，并可与插件的玻璃管道对接。全部功能由插件实现，界面均为箱子界面，**无需安装任何 mod**。

本篇介绍从寻找陨石到组建第一个网络的完整流程；自动合成请查看[应用能源（自动合成）](/linsmagic/atlas/tutorials/systems/ae-autocrafting)。全部 AE 物品可在[应用能源分类](/linsmagic/atlas/ae/)中查询，游戏内也可在芸集知识之书主界面点击「应用能源指南」查看。

::: tip 与原版 AE2 的区别
本系统以玩家体验优先，与 AE2 存在以下主要区别：无需频道线缆，所有 AE 方块相邻即组网；控制器不是多方块结构；合成 CPU 形状不限；分子装配室不必贴着样板供应器；晶体改为在晶体催化器中培育，不再扔进水里。
:::

## 开荒路线 {#s-route}

以下路线与游戏内「应用能源指南」一致，按顺序进行即可：

| 步骤 | 内容 | 详见 |
| --- | --- | --- |
| 1 | 合成 <LmItem id="陨石罗盘" />，前往失落废墟都市寻找陨石 | [第 1 节](#s-meteor) |
| 2 | 开启陨石中心的神秘方块，获得压印模板、陨石碎块与少量水晶 | [第 1 节](#s-meteor) |
| 3 | 挖掘陨石石，获得 <LmItem id="陨石碎块" /> | [第 1 节](#s-meteor) |
| 4 | 将陨石碎块放入原石粉碎机的输入箱子，磨成 <LmItem id="赛特斯石英粉" />（1 → 2） | [第 2 节](#s-chain) |
| 5 | 石英粉与沙子合成种子，种子在 <LmItem id="晶体催化器" /> 中长成 <LmItem id="赛特斯石英水晶" /> | [第 2 节](#s-chain) |
| 6 | 水晶放入红石充能桩或充能器，得到 <LmItem id="充能赛特斯石英" /> | [第 3 节](#s-machines) |
| 7 | 在晶体催化器中反应出 <LmItem id="福鲁伊克斯水晶" /> | [第 2 节](#s-chain) |
| 8 | 将 <LmItem id="压印器" /> 与 <LmItem id="ME能源接收器" /> 相邻放置，放入燃料，压制电路板 | [第 3 节](#s-machines) |
| 9 | 组装处理器，搭建能源接收器 + 驱动器 + 终端 + 1k 存储元件的第一个网络 | [第 4 节](#s-network) |

::: tip 与插件原有物品的联动
应用能源的配方用到了不少插件原有物品：<LmItem id="硅晶细沙" />（提纯为硅）、<LmItem id="魔力灌注钻石" />（工程电路板）、<LmItem id="辉光银锭" />（逻辑电路板）、<LmItem id="魔力粉末" />（组装处理器）、<LmItem id="铁皮" />、<LmItem id="导魔管" />（线缆）、积聚的魔素（燃料与晶体催化器）等。开始前可先准备一些。
:::

## 第 1 节：寻找陨石 {#s-meteor}

### 陨石的位置

- 陨石**只出现在失落废墟都市**世界（可通过[次元枢纽](/linsmagic/atlas/guide/hub)前往）。
- **天然陨石**：新生成的荒野区块有 0.4% 概率出现陨石，已生成的区块不会补充。
- **坠落陨石**：该世界有玩家时，每 15 分钟判定一次，有 50% 概率在某位玩家附近 32～80 格处落下一颗陨石，伴有火焰拖尾动画，落地时砸出陨石坑。[星星之夜](/linsmagic/atlas/events/starry-night)期间坠落概率为 2.5 倍。
- 在失落废墟都市中右键 <LmItem id="陨石罗盘" />，罗盘会指向 **2000 格**内最近的**未开启**陨石。还没有人去过（区块尚未生成）的地方也能感应到，聊天栏会提示「尚未探明区域」；这类陨石要走近、区块生成后才会真正出现，偶尔会因为落点是水面而没有生成，此时再右键一次罗盘即可换下一个目标。

<AtlasRecipe id="ae_meteorite_compass" />

### 陨石的结构

陨石坑中间是一个半径 2～3 格的球体，由**陨石石**（外观为錾制深板岩）组成，正中心是**神秘方块**（外观为珠光蛙明灯），周围散落粗泥、沙砾、黑石、岩浆块等。

| 方块 | 获得 |
| --- | --- |
| 陨石石 | 1 个陨石碎块，30% 概率额外 1 个；时运每级额外 +15% 概率 |
| 神秘方块（右键或挖掉均可开启） | 1 个压印模板（**优先给予该玩家尚未从陨石中开到过的种类**）；25% 概率额外 1 个随机压印模板；2～4 个陨石碎块；1～3 个赛特斯石英水晶 |

::: warning 挖掘规则
- 同一位置的陨石石**只掉落一次**，挖掉后放回再挖不会再次掉落。
- 创造模式挖掘陨石石不会掉落碎块。
- 压印模板的发放按玩家的开启记录判断，与背包中是否已有模板无关。四种模板均开到过后改为随机。
:::

## 第 2 节：材料链 {#s-chain}

应用能源的基础材料按以下顺序加工：

**陨石碎块 → 赛特斯石英粉 → 赛特斯石英种子 → 赛特斯石英水晶 → 充能赛特斯石英 → 福鲁伊克斯水晶**

| 步骤 | 方法 |
| --- | --- |
| 陨石碎块 → 赛特斯石英粉 | 放入[原石粉碎机](/linsmagic/atlas/tutorials/systems/multiblock#s-crusher)的输入箱子，1 个 → 2 个；有压印器后也可研磨，1 个 → 1 个 |
| 赛特斯石英粉 → 种子 | 赛特斯石英粉 + 沙子，工作台合成，一次 2 个 |
| 种子 → 赛特斯石英水晶 | 放入晶体催化器中格培育 |
| 水晶 → 充能赛特斯石英 | 放入红石充能桩或充能器 |
| 充能赛特斯石英 → 福鲁伊克斯水晶 | 晶体催化器：上格红石粉 + 中格充能赛特斯石英 + 下格下界石英，每份 2 个；也可在工作台合成，但只得 1 个 |

### 充能器与红石充能桩

- <LmItem id="充能器" />：需要有电的网络，赛特斯石英水晶 → 充能赛特斯石英，每个 0.5 秒、200 AE，加速卡最多 4 张。也可为 ME无线终端充电，充满后移至输出格等待取出，不会存入网络。
- **红石充能桩**（V1～V6、FAX）也可为赛特斯石英水晶充能，无需 ME 网络，适合开荒阶段使用。

::: tip 红石充能桩改为逐步充能
红石充能桩现已从「关闭界面瞬间充满」改为**逐步充能**：
- 右键打开：左格放红石块（仅接受原版红石块），右格放需要充能的物品，最右侧为成品格（只能取出）。中间一格显示状态、进度条、速度、余能、还需几个红石块与预计剩余时间。
- 放入即开始充能，关闭界面后仍会继续（所在区块加载时）。物品存放在充能桩中，重启不会丢失；拆除或被炸毁时内部物品会掉落。
- 可充能物品：I～X-凌月飞行器、ME无线终端、赛特斯石英水晶（每 2 点能量充好 1 个，放入成品格）。
- 未用完的红石块能量会作为「余能」保留，下次继续使用。

| 充能桩 | 每个红石块的能量 | 每秒消耗红石块 | 充能速度（能量/秒） |
| --- | --- | --- | --- |
| V1 | 4 | 1 | 4 |
| V2 | 5 | 1.25 | 6.25 |
| V3 | 6 | 1.5 | 9 |
| V4 | 8 | 2 | 16 |
| V5 | 9 | 2.5 | 22.5 |
| V6 | 10 | 3 | 30 |
| FAX | 32 | 6 | 192 |

例如：I-凌月飞行器（200 能量）使用 V1 约 50 秒充满；X-凌月飞行器（47,480 能量）使用 FAX 约 4 分钟充满。凌月飞行器只在飞行时耗电，I 型每秒 5 点，充满约可飞 40 秒；型号越高耗电越低、电池越大，VIII 型充满约可飞 22 分钟，X 型约 26 小时。
:::

::: details 管道自动送料
[传入阀](/linsmagic/atlas/tutorials/systems/pipeline#s-first)对准压印器、充能器、晶体催化器时，物品会**自动分入对应格子**：压印器中模板与电路板进入上格、印刷硅板进入下格、其余进入中格；晶体催化器中红石粉进入上格、下界石英进入下格。传入阀对准能源接收器时可自动补充燃料。
:::

## 第 4 节：组建网络 {#s-network}

<LmScene id="ae-first-network" />

### 组网规则

- 所有 AE 方块**六面相邻即相连**，组成同一个网络，无需专门的频道线缆。<LmItem id="ME线缆" /> 只是成本最低的导体，用于拉开距离。
- 使用 <LmItem id="ME扳手" /> 剪断的线缆侧不参与组网，可用于隔开相邻的两个网络（见[第 7 节](#s-tools)）。
- 网络中所有方块所在区块均未加载时，网络会冻结：不耗电、不工作，合成暂停。
- AE 方块不受爆炸影响，无法被活塞推动，也不会被末影人搬走。

### 领地内共用网络 {#s-residence}

ME 设备放在领地里时，别人能不能用由领地权限决定。领地主人本人总是可以使用。

| 操作 | 需要的领地权限 |
| --- | --- |
| 打开终端、驱动器等界面，使用存储监控器 | `aeuse`（未单独设置时跟随 `container`，即开箱子的权限） |
| 用 ME扳手 拆装、改朝向，把无线终端绑定到访问点 | `destroy`（破坏方块） |

想让朋友一起用自己的 AE 网络，但不想让对方拆家，领地主人站在领地内输入：

```
/res pset 玩家名 aeuse true
```

也可以用 `/res pset 玩家名 container true`，这样对方同时能打开领地里的箱子。领地外的 ME 设备所有人都能使用。

### 设备名额

终端、驱动器、总线、接口、样板供应器、分子装配室、电平发射器、存储监控器、无线访问点等「设备」会占用名额：

- 没有控制器时，一个网络最多接入 **8 台**设备。
- 每个 <LmItem id="ME控制器" /> 方块 **+32 台**，最多计算 7 个（上限 232 台）。控制器是单个方块，不是多方块结构。
- 线缆、控制器、能源方块、合成 CPU 部件、压印器、充能器、晶体催化器**不占用名额**。
- 超出上限时，距离控制器较远的设备会先离线。

### 能量

<LmItem id="ME能源接收器" /> 燃烧燃料发电。网络储能已满时，燃料的能量会先存在接收器中，**不会浪费**。

| 燃料 | 每个提供 AE |
| --- | --- |
| 红石粉 | 3,200 |
| 红石块 | 28,800 |
| 煤炭 / 木炭 | 6,400 |
| 煤炭块 | 57,600 |
| 烈焰棒 | 9,600 |
| 烈焰粉 | 4,000 |
| 积聚的魔素（任意一种） | 160,000 |
| <LmItem id="熔火能源核心" /> | 600,000 |
| <LmItem id="能源矩阵" /> | 6,000,000 |
| <LmItem id="永恒燃料" /> | 不消耗，持续提供 20 AE/秒 |

| 储能方块 | 容量 |
| --- | --- |
| ME控制器 | 8,000 AE |
| ME能源接收器 | 4,000 AE |
| <LmItem id="能源元件" /> | 200,000 AE（拆下时保留能量） |
| <LmItem id="致密能源元件" /> | 1,600,000 AE（拆下时保留能量） |

各设备的待机耗电可在物品资料页中查看。作为参考，10 台设备左右的小型网络约耗电 8 AE/秒，一个红石块约可使用 1 小时。网络通电时控制器会亮起。

## 第 5 节：存储与终端 {#s-storage}

### 存储元件

存储元件由 <LmItem id="ME存储外壳" /> 与存储组件合成，共五档：

| 元件 | 容量 | 每种物品的类型开销 |
| --- | --- | --- |
| <LmItem id="ME存储元件-1k" /> | 1,024 字节 | 8 字节 |
| <LmItem id="ME存储元件-4k" /> | 4,096 字节 | 32 字节 |
| <LmItem id="ME存储元件-16k" /> | 16,384 字节 | 128 字节 |
| <LmItem id="ME存储元件-64k" /> | 65,536 字节 | 512 字节 |
| <LmItem id="ME存储元件-256k" /> | 262,144 字节 | 2,048 字节 |

- 每个元件最多存放 **63 种**物品。每种物品先占用「类型开销」，之后每 8 个物品占用 1 字节。
- 元件放入 <LmItem id="ME驱动器" />（10 格）或 <LmItem id="ME箱子" />（1 格）后即接入网络。
- 元件中的物品**跟随元件本身**：将元件取出或移至其他驱动器，物品会一同转移。
- 手持元件**潜行右键空气**：设置分区，只存放指定物品。
- 手持**空**元件**潜行左键空气**：拆回存储外壳与存储组件（有物品时无法拆解）。
- 高档存储组件需要插件原有的高级材料：<LmItem id="红石能量回路" />（4k）、<LmItem id="辉耀结晶" />（16k）、<LmItem id="星彩机器模块" />（64k）、<LmItem id="深岩钢玉" />（256k）。

### 终端

<LmItem id="ME终端" />、<LmItem id="ME合成终端" />、ME箱子自带的终端与 ME无线终端的操作相同：

| 操作 | 效果 |
| --- | --- |
| 左键 / 右键网络物品 | 取出一组 / 半组到光标 |
| Shift+左键网络物品 | 取出一组直接放入背包 |
| 数字键网络物品 | 取出一组放到对应快捷栏 |
| Shift+右键网络物品 | 下单自动合成（仅限可合成物品） |
| 拿着物品点击物品区 | 左键全部存入，右键存入 1 个 |
| 背包中 Shift+点击 | 将该组物品存入网络 |
| 「一键存入」按钮 | 左键存入背包（不含快捷栏），右键连同快捷栏一起存入（手持物品除外） |
| 搜索 | 在聊天栏输入，中文名与英文 ID 均可搜索；右键清空 |
| 排序 | 按名称 / 数量 / 物品 ID，右键切换升降序 |
| 显示 | 全部 / 仅库存 / 仅可合成 |
| 「网络信息」按钮 | 显示能量、存储字节、物品种数、设备名额、可合成种数 |

- **ME合成终端**：额外带有 3×3 合成格，合成后自动从网络补充材料，Shift 点击产物可批量合成。
- **ME箱子**：右键打开终端（未放入元件时打开元件槽），潜行右键打开元件槽。

## 第 6 节：总线、接口与管道 {#s-bus}

### 总线

| 总线 | 作用 |
| --- | --- |
| <LmItem id="ME输入总线" /> | 从贴着的容器中将物品抽入网络 |
| <LmItem id="ME输出总线" /> | 将过滤列表中的物品送入贴着的容器或机器；装入合成卡后，没有库存时自动下单合成 |
| <LmItem id="ME存储总线" /> | 将贴着的容器（箱子、木桶、潜影盒、漏斗、发射器、投掷器）视为网络存储的一部分；可设置优先级、过滤与读写模式（读写 / 只读 / 只写）。熔炉、酿造台等有固定槽位的方块不支持 |

- **朝向**：放置时朝向所贴的方块（若贴的是 AE 方块，则自动寻找相邻容器）；可使用 ME扳手右键或网络分析仪潜行右键切换。
- **搬运速度**：每次 16 个，每 1 秒一次；每张加速卡使搬运量翻倍、间隔缩短（1 张 0.5 秒，2 张起 0.25 秒），最多 4 张（每次 256 个）。
- **过滤槽**：输入 / 输出总线默认 1 格，每张容量卡 +4 格（最多 2 张，共 9 格）；存储总线 18 格。反相卡可将过滤列表改为黑名单。

### ME接口：与管道对接

<LmScene id="ae-pipe-bridge" />

<LmItem id="ME接口" /> 是 ME 网络与插件[玻璃管道](/linsmagic/atlas/tutorials/systems/pipeline)之间的桥梁：

- **传入阀对准接口**：管道中的物品直接存入网络。
- **传出阀或单向运输器对准接口**：取出接口中「备好的货」。
- **右键接口设置备货**（9 格）：接口会从网络中取出这些物品放在自身缓冲中；装入合成卡后，备货不足时自动下单合成。
- 其他可由传入阀直接送料的 AE 方块：压印器、充能器、晶体催化器（自动分格）、能源接收器（补充燃料）。

::: tip 用管道把整个基地接入网络
农场、矿机、刷怪塔等的出货箱通过管道接到 ME接口，产物即可自动进入网络，在任意终端中统一存取。需要把物品送回机器时，再用接口备货 + 传出阀送出。
:::

## 第 7 节：其他设备、工具与升级卡 {#s-tools}

### 其他设备

- <LmItem id="ME电平发射器" />：右键设置物品、阈值（默认 64）与比较方式（高于 / 低于），按网络中该物品的数量输出红石信号。
- <LmItem id="ME存储监控器" />：方块上方悬浮显示一种物品及其网络库存。拿着物品右键设为监视该物品；已监视时拿着同种物品右键，整组存入网络；空手右键取出一组；潜行空手右键清除。
- <LmItem id="ME无线访问点" />：向周围 48 格发射网络信号，供 <LmItem id="ME无线终端" /> 使用。无线终端的用法见[自动合成篇](/linsmagic/atlas/tutorials/systems/ae-autocrafting#s-wireless)。

### 工具

| 工具 | 用法 |
| --- | --- |
| <LmItem id="网络分析仪" /> | 右键 AE 方块：聊天栏显示所在网络的能量、设备、存储与合成 CPU；潜行右键总线：切换朝向；拿在手上时，附近 AE 设备会显示状态粒子：绿色为在线，橙色为未分到设备名额，红色为没电 |
| <LmItem id="ME扳手" /> | 右键线缆的某一侧：剪断 / 接回该侧（点击伸出的臂即为臂的方向，点击中间柱体即为点击的面）；右键总线：切换朝向；潜行右键任意 AE 方块：直接拆下，内部物品一同掉落；右键其他 AE 方块照常打开界面 |

剪断的线缆侧既不显示连接，也不参与组网，可用于隔开相邻的两个网络，或让线缆外观更整齐。剪断信息会保存，新放置的线缆不会连向已剪断的一侧。

### 升级卡

| 升级卡 | 可安装于 | 效果 | 上限 |

| <LmItem id="加速卡" /> | 输入 / 输出总线、分子装配室、压印器、充能器、晶体催化器 | 总线：搬运量翻倍、间隔缩短；机器：加工时间按 1 ÷ (1 + 卡数) 缩短 | 4 |

### 方块信息提示

看向插件的机器或 ME 方块时，快捷栏上方会显示方块名称与状态，例如 AE 方块的在线状态、能量、元件数、加工进度、CPU 任务进度，以及线缆已剪断的方向。

- 显示范围为 6 格，旁观模式不显示。
- 该提示优先级最低，3 秒内有血月倒计时、技能提示等其他快捷栏提示时会自动让路。
- 可在芸集知识之书的**个人设置**（主界面玩家头像）中关闭，也可开启「方块信息包括原版方块」以显示原版方块的中文名。

::: tip 关于 Jade
Jade 等客户端 mod 查看插件方块时显示的是原版方块名（例如「黑色带釉陶瓦」），请以快捷栏上方的方块信息提示为准。
:::

## 常见问题 {#s-faq}

| 现象 | 原因 | 解决方法 |
| --- | --- | --- |
| 压印器、充能器不工作 | 未接入有电的网络 | 与能源接收器相邻放置或用线缆连接，并放入燃料 |
| 晶体催化器很慢 | 未通电，时间为 3 倍 | 接入有电的网络，并可安装加速卡 |
| 部分设备离线，分析仪显示橙色粒子 | 设备名额不足 | 放置 ME控制器（每个 +32 台） |
| 整个网络不工作 | 没电，或所在区块均未加载 | 补充燃料；保持区块加载 |
| 压印模板、石英玻璃无法放在地上 | AE 材料防误放，右键地面不会放置 | 属于正常现象，这些是材料而非方块 |
| 两个网络意外连在一起 | AE 方块相邻即组网 | 用 ME扳手剪断相邻一侧的线缆，或拉开距离 |
| 找不到陨石 | 不在失落废墟都市，或 2000 格内陨石均已开启 | 前往失落废墟都市使用陨石罗盘，罗盘也能感应未探索区域；或等待坠落陨石 |
| 罗盘指向的地方没有陨石 | 该处尚未探明，落点是水面所以没有生成 | 再右键一次罗盘，换下一个目标 |
| 提示「你没有权限使用这里的 ME 设备」 | 设备在别人的领地里 | 请领地主人执行 `/res pset 你的名字 aeuse true`，见[领地内共用网络](#s-residence) |
| 神秘方块总是给同一种模板 | 其余模板已开到过 | 四种都开到过后改为随机；可用压印器复制模板 |
| 存储元件放不进物品 | 已达 63 种或容量已满 | 更换更大容量的元件，或为元件设置分区 |
