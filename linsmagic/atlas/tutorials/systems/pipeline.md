# 管道系统教程

管道可将容器中的物品自动抽出，沿玻璃管道输送至另一个容器，途中还可进行分流、按物品分拣、计数与隔空传输。刷石机、农场、矿机的产物均可通过管道自动存入仓库。

本篇从最简单的「两只箱子」开始，先搭建一条可运转的线路，再逐步添加功能。每一节均配有可拖动旋转的 3D 示意图，鼠标悬停方块可查看说明，点击方块可打开资料页。

::: tip 读这篇需要多久
第 1～3 节约需 10 分钟，阅读后即可搭建第一条可用的管道。后续章节可在需要时查阅。
:::

## 认识零件 {#s-parts}

以下零件了解即可，无需记忆。搭建最小链路只需要前三种。

| 零件 | 作用 | 适用场景 |
| --- | --- | --- |
| <LmItem id="管道玻璃-A型" /> | 物品在其中移动的管道。A/B/C/D 四种颜色互不相通 | 任何线路 |
| <LmItem id="传出阀" /> | 从相邻容器中**抽出**物品送入管道，每 0.5 秒 1 个 | 线路起点 |
| <LmItem id="传入阀" /> | 将管道中的物品**送入**相邻容器 | 线路终点 |
| <LmItem id="行通阀" /> | 相邻有容器时，既会从容器中抽取，也会将经过的物品送入容器；相邻无容器时，原木两端可作为管道使用 | 一条线路串联多个箱子 |
| <LmItem id="下界合金管道-A型" /> | 速度为 6 倍、单程 256 格的管道，与同型号普通管道相通 | 长距离主干 |
| <LmItem id="下界合金传出阀" /> | 每次抽取一整组（最多 64 个） | 大批量出货 |
| <LmItem id="6向分流器" /> | 依次发往每个接有管道的方向 | 一分多 |
| <LmItem id="均分分流器" /> | 将一组物品按数量平均分配给各出口 | 为多台机器平均供料 |
| <LmItem id="平衡分流器" /> | 优先送往剩余空间最多的终点箱 | 多个仓库箱均匀存放 |
| <LmItem id="过滤-放行器" /> | 与样品相同的物品直行，其余转向 | 按物品分拣 |
| <LmItem id="过滤-调转器" /> | 与样品相同的物品转向，其余直行 | 挑出特定物品 |
| <LmItem id="单向运输器" /> | 无需阀门，直接从相邻容器抽取，朝尖端方向输送，仅限水平 | 短距离、节省阀门 |
| <LmItem id="管道侦测器" /> | 直通，有物品经过时让背对它的比较器输出一次信号，流量越大信号越强 | 红石联动 |
| <LmItem id="末影发送口" /> + <LmItem id="末影接收口" /> | 无需管道，在同一世界 50 格内隔空传输 | 跨越河流、山体 |
| <LmItem id="填充机核心" /> + <LmItem id="填充机输出口" /> | 一根管道即可将整排箱子从低到高依次装满 | 大型仓库 |
| <LmItem id="跨维传送器" /> | 两台同名传送器放置在不同维度，可跨维度传送管道物品 | 下界 / 末地物流 |
| <LmItem id="ME接口" /> | 应用能源的 ME 接口，传入阀对准时物品直接存入 ME 网络 | 接入 ME 网络 |

另有几种较少使用的零件：<LmItem id="吸纳整合桶" />（瞬间吸取正上方漏斗中的物品）、<LmItem id="简易排列器" />、<LmItem id="排列器" /> 与 <LmItem id="高级排列器" />（凑齐设定的组合后才放行，见[按组合放行](#s-arranger)）、<LmItem id="潜影盒接收器" />（受红石触发时将上方潜影盒整体收入管道）。详细说明可在资料页中查看。

管道玻璃成本较低：4 个铁锭 + 4 块黑色染色玻璃 + 1 个红石，**一次产出 16 格**。成本主要在阀门。搭建下方的最小链路（2 个阀门 + 3 格管道）约需准备：

- **28 个铁锭**：一次管道合成需要 4 个；每个阀门需要 12 个（含铁皮与漏斗）。
- 4 块黑色染色玻璃、1 个红石、2 个红石块。
- 2 个侦测器：需要下界石英，请先前往下界。
- 2 个漏斗。
- 2 块遮光玻璃：需要紫水晶碎片，可在地下紫水晶洞中挖掘。

::: warning 必须是合成出来的管道玻璃
原版黑色染色玻璃放置后不会成为管道。管道零件均为带有魔法标记的物品，放置时才会登记进管道网络。
:::

## 第 1 节：搭建第一条线路 {#s-first}

<LmScene id="pipe-basic" />

请按编号顺序放置：

1. 放置两只箱子，中间间隔几格。
2. 手持 <LmItem id="传出阀" />，**准星对准左侧箱子的侧面**，右键放置。
3. 从阀门另一侧开始铺设 <LmItem id="管道玻璃-A型" />，一直铺到右侧箱子前一格。
4. 手持 <LmItem id="传入阀" />，**准星对准右侧箱子的侧面**，右键放置，阀门会自动与相邻管道连接。
5. 向左侧箱子中放入几个圆石。每 0.5 秒会有 1 个圆石从阀门送出，在管道中移动，最终进入右侧箱子。

<figure class="lm-shot"><img src="/linsmagic/tutorials/pipe-running.webp" alt="游戏内效果：物品在管道中移动，上方数字为该堆物品的数量。左侧白色的是传出阀，右侧深色的是传入阀。" loading="lazy" /><figcaption>游戏内效果：物品在管道中移动，上方数字为该堆物品的数量。左侧白色的是传出阀，右侧深色的是传入阀。</figcaption></figure>

线路运转成功即表示已掌握最核心的部分，后续所有玩法均是在此线路上添加零件。

::: details 为什么每次只抽 1 个？
普通 <LmItem id="传出阀" /> 每 0.5 秒抽取 1 个，即每秒 2 个，足以满足日常使用。需要搬运大量物品时，请更换为 <LmItem id="下界合金传出阀" />，每 0.5 秒抽取一整组。同一格管道中的同种物品会自动合并为一堆，管道上方显示的数字即为该堆的数量。
:::

## 第 2 节：阀门方向（最容易出错的地方） {#s-valve}

**阀门的朝向由放置时右键点击的方块决定。**对着箱子放置，阀门即朝向箱子；对着管道放置，阀门即朝向管道。

阀门外形为一根原木，两端均有年轮。对着箱子放置与对着管道放置的外观完全相同，但前者可以正常工作，后者永远不会工作。因此：

- **先放置箱子，再对着箱子放置阀门，最后铺设管道。**
- 若线路不运转，最快的解决方法是拆除阀门，重新对着箱子放置。
- 行通阀、单向运输器同样按「点击的方块」确定方向。

::: tip 单向运输器的方向相反
<LmItem id="单向运输器" /> 放置后，**尖端背对所点击的方块**。因此对着箱子放置时，它会从该箱子抽取物品，并朝尖端方向送出。单向运输器只能水平放置，放在地面或天花板上时会自动转为水平方向。
:::

## 第 3 节：管道走向 {#s-rules}

### 连接规则

- 管道零件会在**上下左右前后 6 个方向**上与相邻的管道零件自动连接，无需额外操作。
- **A、B、C、D 四种管道玻璃之间互不相通**，两条不同颜色的管道可以紧贴并排铺设而互不干扰。阀门、分流器等零件则与任何颜色均可连接。
- 下界合金管道分为 A～D 四个型号，与**同型号**的普通管道相通。
- **两条同颜色的管道紧贴时会发生串线**，物品可能转入相邻的线路。并排铺设时请使用不同颜色。

### 岔路

- 普通管道遇到分叉时会**随机**选择一个方向，不会原路返回。
- 如需有规律地分配，请在分叉处放置分流器（见第 4 节）。
- 物品走到死路（前方既无管道也无阀门）时，会从该处**弹出并掉落在地上**。

### 速度与距离

| | 普通管道玻璃 | 下界合金管道 |
| --- | --- | --- |
| 移动速度 | 每秒 2 格 | 每秒约 12 格 |
| 单程最远 | 64 格 | 256 格 |

- 物品在哪种管道中就按哪种速度移动，两种管道可以混合铺设。
- 单程距离在物品**刚离开阀门**时即已确定：若阀门后第一格为下界合金管道，该批物品可移动 256 格，否则只能移动 64 格。因此长线路的第一格务必使用下界合金管道。
- 超出距离的物品会掉落在地上。

### 区块与拆除

- 物品进入未加载的区块时会暂停，区块重新加载后继续移动，不会丢失。服务器重启后，管道中正在移动的物品也会保留。
- 拆除一格管道时，其中正在经过的物品会掉落。

## 第 4 节：分流与分拣 {#s-split}

### 一分多

<LmScene id="pipe-split" />

三种分流器的区别：

| | 分配方式 | 适用场景 |
| --- | --- | --- |
| <LmItem id="6向分流器" /> | 每来一堆物品，依次轮到下一个出口 | 一般分配 |
| <LmItem id="均分分流器" /> | 将一堆物品按数量平均分配（64 个、4 个出口 → 各 16 个），余数依次分配 | 为几台相同机器平均供料 |
| <LmItem id="平衡分流器" /> | 沿每个出口找到终点箱，送往剩余空间最多的一路 | 使几个仓库箱装得一样满 |

分流器的「出口」指除来路以外接有管道的面，上下两面同样计算在内。未接管道的面不会输送物品。

### 按物品分拣

<LmScene id="pipe-filter" />

1. 在需要分拣的位置放置 <LmItem id="过滤-放行器" />，前后均接上管道。
2. **右键**打开 5 格设置界面，放入样品，最多 5 种。样品仅作为模板，关闭界面后会被记住，**不会被消耗**。
3. 与样品相同的物品**直行**；不同的物品依次转向侧面（包括上下）接有管道的方向。
4. 若侧面或直行方向未接管道，应走该方向的物品会被弹出。

<figure class="lm-shot lm-shot-narrow"><img src="/linsmagic/tutorials/filter-gui.webp" alt="右键过滤器打开的设置界面：上方 5 格放入样品，关闭界面后自动保存。" loading="lazy" /><figcaption>右键过滤器打开的设置界面：上方 5 格放入样品，关闭界面后自动保存。</figcaption></figure>

魔法物品按魔法物品种类区分，不会与同材质的原版物品混淆。

<LmItem id="过滤-调转器" /> 的逻辑正好相反：相同的物品转向，其余直行。适用于从大量杂物中挑出特定物品。

::: tip 分拣整个仓库
将多个过滤器串联在一条主线上，每个过滤器侧面接一个箱子，即可组成一台自动分类机：第一个挑出圆石，第二个挑出铁锭，第三个挑出钻石……剩余物品直行进入「杂物箱」。
:::

### 按组合放行：排列器 {#s-arranger}

排列器用于给机器按配比供料：设定一个「组合」，凑齐一整组后才一起放行。共三种，依次升级合成：

| 排列器 | 组合种类 | 暂存上限 | 说明 |
| --- | --- | --- | --- |
| <LmItem id="简易排列器" /> | 5 种 | 2,000 件 | 只需铁锭、红石、漏斗和侦测器，**新手推荐** |
| <LmItem id="排列器" /> | 5 种 | 10,000 件 | 由简易排列器升级 |
| <LmItem id="高级排列器" /> | 9 种 | 100,000 件 | 由排列器升级，另有多项设置，见下文 |

简易排列器与排列器的用法完全相同，只有暂存上限不同：

1. **右键**排列器打开 5 格界面，放入物品，数量即每组所需数。例如 2 个铁锭 + 1 个红石，表示每凑齐 2 铁锭和 1 红石放行一组。
2. 不在组合里的物品直接弹出到地上。
3. 凑齐一组后，从进来方向以外接有管道的面随机选一个送出。
4. 暂存超过上限（简易排列器 2,000 件、排列器 10,000 件）的部分会被**送进垃圾桶销毁**。某种材料来得远比另一种多时，多出的那种会一直囤积，最终被销毁。

<LmItem id="高级排列器" /> 由排列器升级而来，右键打开 27 格界面：第一行 9 格放组合，第三行为设置按钮。

| 设置 | 说明 |
| --- | --- |
| 每种上限 | 每种物品最多存「组合里的数量 × 倍数」件，倍数 1～64 可调（左键 +1，右键 -1），默认 8 |
| 超量处理 | 超出上限的部分：**放行**（沿输出方向继续送走，默认）/ **弹出**到地上 / **销毁**（送进垃圾桶） |
| 不在组合里的物品 | **弹出**（默认，与普通排列器相同）或**放行**（直接送走，不占暂存） |
| 输出方向 | 随机，或固定东、南、西、北、上、下中的一面；该面没有管道或正是物品进来的方向时改为随机 |
| 红石暂停 | 开启后，高级排列器有红石信号时只收不放，断电后将攒够的组合一次放完 |

高级排列器总暂存上限为 100,000 件。使用「超量处理：放行」时，贵重材料不会因为配比失衡而被销毁，多出来的部分会继续流向后方的仓库。界面右侧的书显示当前每种物品的暂存量与上限。

## 第 5 节：机器自动进出料 {#s-machine}

许多多方块机器使用箱子进料、木桶出料。为其接入管道后，即可从仓库自动供料，并自动收取成品。下面以新手最早可制作的 <LmItem id="原石粉碎机核心" /> 为例：

<LmScene id="crusher-auto" />

要点：

- **进料**：将 <LmItem id="传入阀" /> 对准机器的**输入箱**放置。
- **出料**：将 <LmItem id="传出阀" /> 对准机器的**输出木桶**放置。
- 机器自身的结构方块（四角的圆石）请勿替换为管道，阀门接在输入箱、输出桶的外侧即可。
- 管道可送入的容器包括：箱子、陷阱箱、木桶、潜影盒、漏斗、发射器、投掷器。熔炉、高炉等容器**无法**由管道直接送入，需要先送入漏斗，再由漏斗向下输送。
- 少数机器设有专门的管道入口。例如[原版矿机](/linsmagic/atlas/tutorials/systems/multiblock#s-ore-miner)的燃料，可使用传入阀直接对着矿机核心输送煤炭或木炭。

## 第 6 节：远距离与大型仓库 {#s-far}

### 末影发送口 / 接收口

<LmScene id="ender-link" />

- **无需管道**：发送口贴着一个容器，接收口贴着另一个容器，频道名相同即可自动传输。
- 设置频道名：右键接口 → 点击「进行命名」→ 在聊天框输入名称（最多 32 个字，输入 `cancel` 取消）。设置完成后，接口上方会显示频道名。
- 两端必须位于**同一世界**，直线距离在 **50 格以内**。同一频道有多个接收口时，物品会送往最近的接收口。
- 传输速度仅取决于**发送口**：普通发送口每 0.5 秒 1 个；<LmItem id="下界合金末影发送口" /> 每秒一整组（64 个）。
- 接收端的箱子已满时，物品会保留在原箱子中，不会丢失。
- 如需跨维度传输，请使用 <LmItem id="跨维传送器" />：为两台传送器设置相同的名称，分别放置在**不同维度**，管道物品送入其中一台后，另一台会将物品送入其相邻的管道。

### 填充机群：一根管道装满一整面墙的箱子

<LmScene id="filler-group" />

- 管道直接连接 <LmItem id="填充机核心" />，无需传入阀。
- 核心与 <LmItem id="填充机输出口" /> 相邻即组成一个「群」。群内每个方块旁的箱子都会被装填，**优先装填最低处**，装满后再向上装填。
- 一个群最多包含 16 个方块（核心与输出口合计），超出后整个群失效，所有物品改走溢出。
- 填充机同样分为 A～D 四个型号，**仅与同型号组成群**，因此不同型号可以紧贴放置而互不干扰。
- 全部装满或核心受红石充能时，物品会改走核心上其他相连的管道（可接入下一个填充群），若无其他管道则弹出至地面。

### 接入 ME 网络

传入阀对准 <LmItem id="ME接口" /> 放置时，管道中的物品会直接存入[应用能源](/linsmagic/atlas/tutorials/systems/applied-energistics#s-bus)的 ME 网络，可在任意终端中统一搜索与存取；传出阀对准 ME接口时，可取出接口中设置好的备货。需要大量存储与分类时，ME 网络是填充机群之外的另一种选择。

### 远程打开箱子：容器远程连接器 {#s-remote-link}

<LmItem id="容器远程连接器" /> 不需要管道，用于在任何地方直接打开一个指定的箱子，适合查看或取用远处仓库里的物品。

1. 手持连接器**右键一个箱子**（普通箱子、陷阱箱均可，大箱子按 54 格打开），即完成绑定。物品说明中会显示绑定的世界、坐标与容器规格。
2. 之后手持连接器**右键空气或任意其他方块**，即可打开绑定的箱子，距离与所在位置不限（绑定的世界需已加载）。再次右键已绑定的箱子本身也会直接打开。
3. 打开的就是箱子本身：漏斗、管道与其他玩家对箱子的改动会实时显示，在界面中存取物品与站在箱子前操作完全相同。

- 连接器为**一次性**道具，每成功远程打开一次消耗 1 个；绑定和打开失败时不会消耗。堆叠的连接器共用同一个绑定。
- 放在副手时与其他副手物品规则相同：主手物品有右键动作（吃东西、放方块、开门等）时优先执行主手，不会误用连接器。
- 界面打开期间，箱子所在区块会保持加载；箱子被拆除或大箱子被拆成单箱时，界面会自动关闭。
- 绑定与打开都需要领地权限：领地内的箱子需要领地主人给予 `aeuse` 或 `container` 权限，与[应用能源的领地规则](/linsmagic/atlas/tutorials/systems/applied-energistics#s-residence)相同。

## 红石控制 {#s-redstone}

<LmScene id="redstone-stop" />

| 充能的方块 | 效果 |
| --- | --- |
| 一格普通管道（或仅连接两侧的零件） | 物品在其前方排队等待，断电后继续移动 |
| 传出阀 | 暂停从箱子中抽取 |
| 传入阀 | 物品在阀门处等待，断电后再送入箱子 |
| 岔路口（连接 3 个及以上方向） | 可强制物品只走某一侧（与周围哪一格带电有关，建议先搭建测试线路确认） |
| 填充机核心 | 视为箱子全满，全部物品走溢出 |

<LmItem id="管道侦测器" /> 为直通零件（从哪面进就从对面出，不会转弯）。在其旁边放置一个**背对它**的比较器，每经过一堆物品，比较器会输出一个短脉冲，可用于在有物品经过时触发其他红石装置。

信号强度反映最近的流量：侦测器会累计最近经过的物品数（每 0.1 秒减 1，最多记 45 个），**每 3 个物品 1 级信号**，最高 15 级。零星经过 1～3 个物品时只有 1 级信号，红石粉只能点亮 1 格；需要传得更远时，在比较器后面接中继器。

## 常见问题 {#s-faq}

| 现象 | 可能原因 | 解决方法 |
| --- | --- | --- |
| 箱子中的物品无法送出 | 阀门是对着管道或地面放置的 | 拆除阀门，**对着箱子**重新放置（[第 2 节](#s-valve)） |
| | 传出阀受到红石充能 | 检查附近的拉杆、红石块、红石火把 |
| | 线路堵塞（终点已满或被红石阻挡），一直堵到阀门处 | 清空终点箱，或断开红石 |
| 物品在途中掉落在地上 | 走到了死路 | 沿线路查找断开处并补上管道 |
| | 超过 64 格 | 将阀门后第一格更换为下界合金管道，或增加中转箱重新出发 |
| | 终点箱已满 | 增加箱子，或使用填充机群、平衡分流器 |
| 物品进入了相邻的线路 | 两条同颜色管道紧贴在一起 | 将其中一条更换为其他颜色（A/B/C/D） |
| 分叉处的物品去向不固定 | 普通岔路为随机分配 | 更换为分流器或过滤器 |
| 过滤器没有分拣 | 直行方向或侧面未接管道；样品与实际物品不是同一种 | 检查两侧管道；魔法物品需使用同种魔法物品作为样品 |
| 物品无法送入熔炉 | 熔炉不是管道支持的容器 | 先送入漏斗，再由漏斗向下送入熔炉 |
| 末影接口不传输 | 频道名不一致；不在同一世界；超过 50 格；两端未贴容器 | 右键两端核对频道名，确认距离 |
| 填充机不装填箱子 | 群超过 16 个方块；型号不一致；核心受红石充能 | 拆分为小群、统一型号、断开红石 |
| 排列器里的物品变少了 | 暂存超过上限（简易 2,000 件、普通 10,000 件），多出的部分被送进垃圾桶 | 调整进料配比，或更换为高级排列器并使用「超量处理：放行」（[按组合放行](#s-arranger)） |
| 容器远程连接器打不开 | 未绑定；绑定的箱子已被拆除；所在世界未加载；没有领地权限 | 查看物品说明中的绑定信息，重新右键箱子绑定；领地内请向主人申请 `aeuse` 权限 |
| 高级排列器不放行 | 开启了红石暂停且有红石信号；组合里某种物品还没凑齐 | 断开红石；查看界面右侧的状态书 |

如仍无法解决，请在[芸集知识之书](/linsmagic/atlas/guide/book)中点击「反馈 bug 与提供更新建议」，并注明坐标与现象。
