# 金耀之月

<LinsMagicEntry id="golden-moon" />

## 事件说明

| 等级 | 说明 |
|------|------|
| **I级** | 金色的月光洒满大地，金甲军团降临！ |
| **II级** | 金耀之月的光辉愈发耀眼…… |
| **III级** | 金色军团披上了更坚固的甲胄！ |
| **IV级** | 金甲怪物们获得了力量加持！ |
| **V级** | 金色军团离地而起，燃起灼金之焰！ |
| **VI级** | 金耀军团势不可挡，金光冲天！ |
| **VII级** | 金光万丈，大地为之颤抖！ |
| **VIII级** | 淘金热！金耀之月的终极形态降临！ |

::: tip 小贴士
- 该事件下所有生物均有金耀月夜特殊掉落物
- [金耀催化剂](/linsmagic/atlas/items/tools/i-935cf70451d5)可主动召唤随机 I～III 级金耀之月。
:::
