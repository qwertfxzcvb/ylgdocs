# 全服增益

<LinsMagicEntry id="server-buffs" />

## 事件说明

![示例](/linsmagic/special3.png)
服务器会随机刷新增益，玩家也可通过使用魔法物品来召唤增益。


| 增益 | 说明 |
|------|------|
| **晴天** | 增益持续时间内，天气恒为晴天。 |
| **雨天** | 增益持续时间内，天气恒为雨天。 |
| **雷暴** | 增益持续时间内，天气恒为雷暴。 |
| **双倍经验** | 增益持续时间内，所有经验掉落均为双倍。 |
| **双倍掉落** | 增益持续时间内，所有物品掉落均为双倍。 |
