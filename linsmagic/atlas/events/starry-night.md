# 星星之夜

<LinsMagicEntry id="starry-night" />

## 事件说明

| 等级 | 说明 |
|------|------|
| **I级** | 璀璨的星尘洒满夜空，怪物们在星光下变得狂暴！ |
| **II级** | 星光愈发炽烈，更多怪物在星辉中熠熠生辉！ |
| **III级** | 漫天星雨倾泻而下，繁星之力笼罩了整片天地！ |
| **IV级** | 最极致的流星爆发！所有怪物都将沐浴在辉煌的星光之中！ |
::: tip 小贴士
- 该事件下所有**发光怪物**均有60%概率掉落**琉璃星星凝晶**
- 可通过`繁星魔法机器`对掉落物加工，自定义想要的粒子效果
:::
