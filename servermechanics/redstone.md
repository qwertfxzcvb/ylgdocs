# 红石与刷怪

## 关于红石

服务器支持红石机器正常运作，只要不严重影响服务器性能，均可正常使用。

::: warning 红石规则
- **禁止卡服机**：任何恶意造成服务器卡顿或性能下降的装置均不允许
- 其余红石装置（如自动农场、自动分类等）均可自由使用
:::

## 关于刷怪

服务器使用 **Paper** 核心，刷怪效率约为 **原版的 70%**。

**为什么刷怪效率会降低？**

Minecraft 原版的刷怪系统对服务器 CPU 消耗极大，如果保持原版刷怪效率，在多人同时在线时服务器会严重卡顿。降低刷怪上限是目前所有大型生存服的通用做法。

**如何应对？**

- 刷怪塔可以适当 **增大规模** 来弥补效率差异
- 利用 **仇恨机制** 提高刷怪塔的效率
- 参考网上针对服务端优化后的刷怪塔设计
