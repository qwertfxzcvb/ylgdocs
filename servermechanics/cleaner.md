# 掉落物清理与垃圾桶

为了保证服务器流畅运行，地上的掉落物会被定时清理。被清理的物品会进入 **垃圾桶**，在垃圾桶清空前都可以找回。

## 掉落物清理

| 规则 | 说明 |
|------|------|
| **定时清理** | 掉落物在地上存在 **10 分钟** 后会被清理 |
| **卡顿应急清理** | 服务器严重卡顿时，会提前清理地上的掉落物 |
| **区块上限** | 单个区块内的掉落物超过 **1000 个** 时，新产生的掉落物会被直接清理 |

以上被清理的掉落物都会进入垃圾桶。

::: tip 建议
死亡或背包满时掉在地上的物品请尽快捡回；刷怪塔、农场的产物建议用漏斗及时收进箱子，避免堆在地上。
:::

## 垃圾桶

```
/trash
```

也可以使用 `/ljt`。

垃圾桶是 **全服共享** 的，所有被清理的掉落物都会放在这里，同种物品合并显示，按数量从多到少排列。界面标题会显示距离下次清空的剩余时间。

### 找回物品

| 操作 | 效果 |
|------|------|
| 左键点击物品 | 取出一组 |
| Shift + 左键点击物品 | 取出该物品的全部 |

### 丢弃物品

不需要的物品也可以直接丢进垃圾桶：

- 在自己背包中 **Shift + 左键** 点击物品，整组丢入
- 拿起物品后点击垃圾桶中的格子：左键放入全部，右键放入一个
- 打开垃圾桶时按 **数字键**，丢入对应快捷栏格子的物品

::: warning 定时清空
垃圾桶每 **24 小时** 清空一次，清空后物品无法找回。由于垃圾桶是全服共享的，丢失的物品也可能已被其他玩家取走，请尽早找回。
:::
