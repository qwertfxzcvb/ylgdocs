# 方块记录与区域回档

服务器使用 **CoreProtect** 插件记录所有方块变动，管理员可以查询记录和回档区域

## 查询方块记录

输入以下命令进入查询模式，然后点击要查询的方块：

```
/co i
```

点击任意方块后会显示该位置的所有操作记录（谁放置/破坏了什么、什么时间）

再次输入 `/co i` 退出查询模式。

## 申请区域回档

如果你的建筑被恶意破坏，请联系管理员进行区域回档：

1. 记录被破坏的大致位置坐标
2. 通过游戏内或QQ联系管理员
3. 提供坐标和被破坏的时间范围

::: info 回档说明
管理员会使用 CoreProtect 将被破坏的区域恢复到指定时间点之前的状态，你自己的正常建造不会受影响
:::
