# 背包回档

如果因为误操作、掉落物品或其他意外导致物品丢失，可以联系管理员申请恢复背包物品。

服务器会持续备份玩家的背包数据，在确认物品确实因意外丢失后，可以根据备份记录进行恢复。

## 申请回档

申请背包回档时，请联系管理员，并说明：

- 丢失的物品
- 大致丢失时间
- 物品丢失的原因
- 需要恢复的大致时间点

## 提供证据

为了避免误操作或恶意申请，背包回档需要提供能够证明物品丢失的证据，例如：

- **[Replay Mod](/guide/suggestedmods/replaymod) 录像**
- 游戏录像或截图
- 其他可以证明物品确实存在并意外丢失的记录

::: warning 注意
仅凭口头描述无法保证能够进行背包回档，请尽量提供完整的录像或其他有效证据。
:::
