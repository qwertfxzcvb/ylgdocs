# 银行

银行可以用于存放金币、取款、每日结息以及查看资金记录。存入银行的金币不会因死亡被扣除

## 打开银行

```
/bank
```

打开银行后，可以查看账户余额、当前利率和下一次结息时间

## 银行功能

| 功能 | 说明 |
|------|------|
| **存款** | 将钱包中的金币存入银行 |
| **取款** | 将银行中的金币取回钱包 |
| **每日结息** | 根据当前账户利率进行每日结息 |
| **交易流水** | 查看存款、取款、每日利息以及管理员调整记录 |

## 存款

在银行界面点击 **存入指定金额**，然后在聊天栏中输入需要存入的金额

普通玩家存款会收取 **0.1% 手续费**，VIP、SVIP 免除

## 取款

在银行界面点击 **取出指定金额**，然后在聊天栏中输入需要取出的金额

普通玩家取款会收取 **0.1% 手续费**，VIP、SVIP 免除

## 每日结息

每天 **0 点**（服务器时间）结算一次，离线期间的结算会在下次打开银行时补上。不同身份的每日利率不同：

| 身份 | 每日利率 | 存取手续费 |
|------|----------|------------|
| 普通玩家 | **-0.5%**（每天扣除余额的 0.5%） | 0.1% |
| VIP | 0%（不扣除） | 免除 |
| SVIP | **+0.5%**（每天获得余额的 0.5%） | 免除 |

银行界面会显示你当前的每日利率和下一次结息时间。

## 会员中心

在银行界面点击 **会员中心**，可以使用 [捐赠点](/economy/donation) 购买 VIP 或 SVIP 月卡、年卡。

## 交易流水

点击银行界面的 **交易流水** 可以查看账户资金变动，包括：

- 存款记录
- 取款记录
- 每日利息
- 管理员调整记录
