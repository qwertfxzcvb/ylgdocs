# 银行

银行可以用于存放金币、取款、每日结息以及查看资金记录

## 打开银行

```
/bank
```

打开银行后，可以查看账户余额、当前利率和下一次结息时间

## 银行功能

| 功能 | 说明 |
|------|------|
| **存款** | 将钱包中的金币存入银行 |
| **取款** | 将银行中的金币取回钱包 |
| **每日结息** | 根据当前账户利率进行每日结息 |
| **交易流水** | 查看存款、取款、每日利息以及管理员调整记录 |

## 存款

在银行界面点击 **存入指定金额**，然后在聊天栏中输入需要存入的金额

普通用户存款会收取 **0.1% 手续费**，高级用户 可免除手续费

## 取款

在银行界面点击 **取出指定金额**，然后在聊天栏中输入需要取出的金额

普通用户取款会收取 **0.1% 手续费**，高级用户 可免除手续费

## 每日结息

银行账户会显示当前的 **每日利率** 和 **下一次结息时间**，具体利率以银行界面显示为准

::: tip 结息时间
每日结息时间以服务器本地时间为准
:::

## 交易流水

点击银行界面的 **交易流水** 可以查看账户资金变动，包括：

- 存款记录
- 取款记录
- 每日利息
- 管理员调整记录
