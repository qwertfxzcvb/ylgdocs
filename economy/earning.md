# 获取金币

服务器金币是主要的经济货币，可以通过多种方式获取。

## 获取途径

| 途径 | 说明 |
|------|------|
| **市场交易** | 与其他玩家交易赚取金币，详见 [市场交易](/economy/market) |
| **箱子商店** | 开设自己的箱子商店赚取金币，详见 [箱子商店](/economy/chestshop) |
| **魔法收购** | 通过行商联络仪的物品收购功能出售指定物品获取金币，详见 [魔法插件](/linsmagic/home)  |
| **地标收费** | 设置收费地标，其他玩家使用时可获得相应金币 ，详见 [地标](/gameplay/landmark) |
| **银行利息** | 将金币存入银行，可定期获得利息收益 ，详见 [银行](/economy/bank.md) |
| **益智游戏** | 参与菜单内的益智小游戏，完成后可获得金币奖励 |

## 查看余额

```
/money
```

## 转账给其他玩家

```
/pay <玩家名> <金额>
```

**示例：**`/pay Steve 100`

## 查看金币排行榜

```
/baltop
```
