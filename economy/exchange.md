# 交易所

烟翎阁交易所是官网上的金融板块，可以查看魔法插件的矿物收购行情，也可以用游戏金币进行外汇交易。

网址：[www.ylg.net.cn/exchange](https://www.ylg.net.cn/exchange)

## 登录交易所

交易所使用 **游戏账号** 登录，和官网账号相互独立：

1. 在游戏内输入 `/exchange`
2. 点击聊天栏中的 **[点击打开烟翎阁交易所]** 链接

::: tip 登录链接
链接 **5 分钟内有效，只能使用一次**，请勿转发给他人。登录状态保留 12 小时，到期后重新在游戏内获取链接即可。
:::

## 金币充值与提现

交易所有独立的账户，游戏金币不会自动同步，需要先充值才能交易。

| 操作 | 说明 |
|------|------|
| **充值** | 从游戏金币中扣除，转入交易所账户，通常几秒内到账 |
| **提现** | 从交易所账户转回游戏金币，玩家离线时也可以处理 |

充值、提现的状态可以在「资产中心」的充提记录中查看。显示「人工核对中」时，由管理员确认后处理。

## 矿物行情

矿物行情展示 [异界行商](/linsmagic/merchant) 的实际收购数据，**只提供行情，不能交易**：

- K 线、价格分布、最新成交、涨跌排行
- 限时收购和大单动态
- LinsMagic 收购指数、矿砂指数和金耀指数，反映整体收购价格的变化
- 收益计算器，估算出售所得

出售物品前可以先在这里看看价格走势。

## 外汇交易

外汇交易使用市场汇率报价，以金币作为保证金，可以 **买入看涨**，也可以 **卖出看跌**。

- **名义金额 = 保证金 × 杠杆**，盈亏按价格变动比例计算，以金币结算
- 每笔持仓的保证金相互独立，**亏损最多为这笔保证金**，账户余额不会变成负数
- 支持市价、限价、突破三种下单方式，可以设置止盈价、止损价
- 开放时间为纽约时间 **周日 17:00 至周五 17:00**，周末休市期间不能开仓、平仓和改单

### 费用

| 费用 | 说明 |
|------|------|
| 点差 | 因品种而异，可在「市场报价」中查看 |
| 开仓手续费 | 下单时显示 |
| 隔夜费 | 持仓过夜时从保证金中扣除，**周三按三倍收取** |

### 强平

持仓权益降到强平线时，系统会自动平仓，防止亏损超过保证金。隔夜费会让强平价逐渐靠近，下单前可以在下单面板查看预估强平价。

::: danger 风险提示
- 杠杆会同时放大盈利和亏损，倍数越高，越小的波动就可能触发强平
- 周末休市后价格可能跳空，止损和强平不保证在设定价格成交
- 请只使用可以承受亏损的金币参与交易
:::

## 资产中心

资产中心集中显示账户净值、盈亏和所有交易记录，包括资产走势、盈亏日历、品种盈亏、多空表现等，成交、流水和充提记录可以筛选和导出。

## 常见问题

| 问题 | 解答 |
|------|------|
| 登录链接打不开 | 链接 5 分钟内有效且只能使用一次，请回到游戏重新输入 `/exchange` |
| 充值后余额没有变化 | 充值由服务器处理，通常几秒内到账，可以在充提记录中查看状态 |
| 金币可以购买或兑换现实货币吗 | 不可以 |
| 账号被封禁后资金怎么办 | 封禁期间不能登录、交易和充提，已有持仓继续按规则结算 |
