# 市场交易

市场系统允许玩家在全服范围内挂售和购买物品，无需面对面交易。

## 出售物品

手持要出售的物品，输入：

```
/market sell <价格>
```

物品会被上架到全服市场，其他玩家可以随时购买。

## 浏览市场

```
/market
```

打开市场界面，浏览所有在售物品并购买你需要的。

## 常用命令

| 命令 | 说明 |
|------|------|
| `/market` | 打开市场界面 |
| `/market sell <价格>` | 上架手持物品 |
| `/market listings` | 查看自己上架的物品 |
| `/market cancel` | 取消自己的上架物品 |

::: tip 交易安全
通过市场系统交易比玩家间直接交易更安全，不用担心对方不守信用。
:::
