# 捐赠教程

感谢你支持烟翎阁服务器的发展！**捐赠所得全部用于服务器的续费和升级**。

## 一、购买捐赠点

1. 前往 [烟翎阁爱发电主页](https://afdian.com/a/ylgserver)，先注册并登录爱发电账号。
2. 点击主页中的 **电铺**，选择需要的捐赠点档位。
3. 点击 **购买**，完成支付。

**每 1 元人民币对应 100 捐赠点**，可选择以下档位：

| 捐赠点 | 金额（人民币） |
| --- | --- |
| 100 | 1 元 |
| 500 | 5 元 |
| 1000 | 10 元 |
| 3000 | 30 元 |
| 5000 | 50 元 |
| 10000 | 100 元 |
| 20000 | 200 元 |
| 50000 | 500 元 |

## 二、获取激活码

支付完成后，查看 **爱发电私信**，系统会自动发送激活码，格式如下：

```text
ACFFF-L5XAX-DC998-PZ5YP-PRC4Q
```

::: tip 激活码说明
上面的激活码仅用于展示格式。兑换时，请使用你在爱发电私信中实际收到的激活码。
:::

## 三、在游戏内兑换

进入服务器后，可以选择以下任意一种方式兑换。

### 方式一：通过兑换界面

1. 在游戏聊天栏输入以下指令，打开兑换界面：

   ```text
   /cdk
   ```

2. 输入私信中收到的激活码。
3. 点击 **确定**，兑换成功后即可获得对应数量的捐赠点。

### 方式二：直接输入指令

在游戏聊天栏输入 `/cdk 激活码` 即可兑换，例如：

```text
/cdk ACFFF-L5XAX-DC998-PZ5YP-PRC4Q
```

请将示例中的激活码替换为你实际收到的激活码。兑换成功后，捐赠点就会到账。

## 四、查看余额

输入以下指令，查看当前捐赠点余额：

```text
/yp balance
```

## 遇到问题怎么办？

如果购买、获取激活码、兑换或到账过程中出现问题，请联系管理员协助解决。
