# 箱子商店

箱子商店允许玩家创建自己的商店，与其他玩家进行自动化交易。

## 创建箱子商店

1. 放置一个 **箱子**
2. 手持要出售的物品
3. **左键** 点击箱子
4. 在聊天栏输入 **出售价格**

商店会自动创建，其他玩家右键点击箱子即可购买。

## 常用命令

| 命令 | 说明 |
|------|------|
| `/qs create <价格>` | 创建出售商店 |
| `/qs buy` | 将商店改为收购模式 |
| `/qs sell` | 将商店改为出售模式 |
| `/qs price <价格>` | 修改商店价格 |
| `/qs remove` | 移除商店（看着箱子输入） |
